## 什么是 MCP Server

DJI Cloud API 2 MCP Server 是一个符合 [MCP 规范](https://modelcontextprotocol.io/) 的中间服务，将 DJI Cloud API 2 SDK 的全部能力（设备管理、飞行控制、媒体管理、航线任务等）暴露为 AI 工具可调用的标准接口。

简单来说：**配置完成后，你可以用自然语言让 AI 帮你操控无人机和机场。**

```
你（自然语言）→ AI Agent → MCP Server → DJI Cloud API 2 SDK → 无人机/机场
```

### 传输协议

MCP Server 当前使用 **SSE（Server-Sent Events）** 传输，协议版本 `2025-06-18`。

> MCP 规范从 2025-03-26 起推荐 **Streamable HTTP** 替代 SSE。本 Server 计划在后续版本跟进。当前所有主流客户端（Claude Code、Cursor、Windsurf 等）均**向下兼容 SSE**，可正常接入。

## 配置接入

### Claude Code

在终端执行：

```bash
claude mcp add --transport sse --scope user \
  --header "Authorization: Bearer <your-token>" \
  dji-cloud-api2 \
  https://<mcp-server-host>/pf-devkit/ai-plugin/mcp/sse
```

配置完成后重启 Claude Code 即可生效。

### Cursor

编辑项目根目录 `.cursor/mcp.json`（如不存在则创建）：

```json
{
  "mcpServers": {
    "dji-cloud-api2": {
      "url": "https://<mcp-server-host>/pf-devkit/ai-plugin/mcp/sse",
      "headers": {
        "Authorization": "Bearer <your-token>"
      }
    }
  }
}
```

保存后重启 Cursor。

## 验证连接

配置完成后，在 AI 工具中输入以下任一指令进行验证：

```
连接 DJI Cloud API 2
```

```
Connect to DJI Cloud API 2 and show session info
```

AI 将自动调用 `fh_connect` 工具。如果返回类似以下信息，表示连接成功：

```
已成功连接到 DJI Cloud API 2 工作空间。
- 工作空间: xxx-workspace
- 会话 ID: session-xxxx
- 连接时间: 2026-08-02T10:30:00
```

如果连接失败，请检查：
1. Token 是否正确且未过期
2. 端点地址是否可访问（尝试浏览器打开 `https://<host>/pf-devkit/ai-plugin/mcp/sse`）
3. 网络是否通畅（是否需要 VPN）

## 基本使用流程

所有操作遵循以下基本流程：

```
1. 建立会话      fh_connect（所有操作的前提，必须第一步）
       │
2. 查询设备      fh_device_list → 获取设备 SN
       │
3. 获取状态      fh_drone_snapshot / fh_dock_snapshot
       │
4. 执行操作      飞行控制 / 航线任务 / 媒体管理 / ...
       │
5. 释放资源      fh_control_release（如有获取控制权）
```

### 飞行操作的前置条件链

如果你需要实时控制无人机飞行（指点飞行、环绕飞行等），需要按以下顺序建立前置条件：

```
fh_connect                → 建立会话
  └── fh_control_acquire  → 获取飞行控制权（互斥资源）
        └── fh_drc_connect → 建立 DRC 低延迟链路
              └── fh_takeoff / fh_flyto / fh_poi ...  → 执行飞行指令
              └── fh_drc_disconnect → 断开 DRC
        └── fh_control_release → 释放控制权（必须！即使出错也要释放）
```

> 不用担心记不住这个链路——AI 会自动按正确顺序调用。你只需要用自然语言描述你想做什么。

## 常用场景示例

### 场景 1：查询设备列表

**你说：**
```
帮我查看当前工作空间里有哪些设备在线
```

**AI 将调用：** `fh_connect` → `fh_device_list`

**返回：** 所有设备的名称、SN、类型、在线状态。

---

### 场景 2：获取无人机实时状态

**你说：**
```
查看无人机 4TADL9D0020B5H 的当前状态
```

**AI 将调用：** `fh_drone_snapshot` 或 `fh_osd_snapshot`

**返回：** 位置（经纬度/高度）、电量、速度、飞行模式、GPS 信号等。

---

### 场景 3：一键起飞并飞到指定位置

**你说：**
```
让无人机 4TADL9D0020B5H 起飞到 50 米高度，然后飞到纬度 22.5862、经度 113.9734 的位置
```

**AI 将调用：**
1. `fh_control_acquire` — 获取控制权
2. `fh_drc_connect` — 建立 DRC 链路
3. `fh_takeoff` — 起飞到 50 米 ⚠️ 需要你确认
4. `fh_flyto` — 飞到目标坐标 ⚠️ 需要你确认
5. 飞行完成后 `fh_drc_disconnect` + `fh_control_release` — 释放资源

> 所有 L2 飞行操作都会弹窗要求你确认后才执行。

---

### 场景 4：执行航线任务

**你说：**
```
查看机场 7CZDM680C200EP 可用的航线，选一条适合的执行飞行任务
```

**AI 将调用：**
1. `fh_wayline_recommend` — 推荐该机场可飞的航线
2. `fh_flight_task`(action=create) — 创建飞行任务
3. `fh_wayline_execute` — 执行航线 ⚠️ 需要你确认

---

### 场景 5：拍照与录像

**你说：**
```
让无人机拍一张照片
```

**AI 将调用：** `fh_camera`(action=camera_photo)

**你说：**
```
开始录像，30 秒后停止
```

**AI 将调用：** `fh_camera`(action=camera_video_start) → 等待 → `fh_camera`(action=camera_video_stop)

---

### 场景 6：环绕兴趣点飞行

**你说：**
```
让无人机围绕机场的位置，以 50 米半径、5 米/秒的速度顺时针环绕飞行
```

**AI 将调用：**
1. `fh_dock_snapshot` — 获取机场 GPS 坐标作为环绕中心
2. `fh_poi`(action=start) — 开始环绕 ⚠️ 需要你确认

> 注意：环绕中心不能是无人机当前位置，需要是一个地面目标（如机场、建筑物）。

---

### 场景 7：紧急返航

**你说：**
```
让无人机立即返航
```

**AI 将调用：** `fh_return_home`(action=start) ⚠️ 需要你确认

如果遇到紧急情况需要立即悬停：

```
紧急停止无人机！
```

**AI 将调用：** `fh_emergency_stop` ⚠️ L3 级别，需要提供原因并确认

## 安全机制说明

MCP Server 实施四级安全模型，保障飞行安全：

| 等级 | 名称 | 操作类型 | 确认方式 |
|------|------|----------|----------|
| **L0** | READ_ONLY | 只读查询（状态、列表） | 无需确认，直接执行 |
| **L1** | REVERSIBLE | 可逆操作（开舱盖、充电） | 需要 `confirm=true` 或弹窗确认 |
| **L2** | FLIGHT | 飞行操作（起飞、飞行、环绕） | 需要控制权 + DRC + 弹窗确认 |
| **L3** | CRITICAL | 紧急停止（不可逆） | 需要 reason + 强制确认 |

### 人工确认弹窗（Elicitation）

在支持弹窗确认的客户端（如 Claude Code），执行 L1 及以上操作时，Server 会**主动弹窗让你确认**：

```
⚠️ 无人机 DRONE-001 即将起飞至 50.0 米高度，是否确认？
[确认] [拒绝]
```

只有你点击「确认」后操作才会执行，拒绝或超时则操作取消。

### 安全等级上限

平台管理员可通过 `FH_MAX_SECURITY_LEVEL` 环境变量设置全局上限：
- 设为 `1`：只允许读取和可逆操作，所有飞行指令被拒绝
- 设为 `2`：允许飞行操作，禁止紧急停止（生产环境推荐）
- 设为 `3`：允许所有操作（仅限紧急场景）

## dry_run 预览模式

所有 L1 及以上的工具支持 `dry_run=true` 参数。当使用 dry_run 时：

- 参数校验和前置条件检查正常执行
- **不会实际调用 SDK 或执行飞行操作**
- 返回"如果真正执行会做什么"的预览信息

**适用场景：**
- 首次使用时验证参数是否正确
- 演示操作流程但不实际执行
- 教学和培训场景

**使用方式：** 告诉 AI "用 dry_run 模式预览一下" 或 "不要真的执行，先给我看看会怎样"。

## 内置 Prompt 模板

MCP 协议的三大原语是 **Tools**（工具调用）、**Resources**（资源读取）和 **Prompts**（提示模板）。DJI Cloud API 2 MCP Server 内置了 5 个业务流程 Prompt，为 AI 提供标准化的操作编排指南。

在支持 Prompt 选择器的客户端（如 Claude Code 的 `/prompts` 命令、Cursor 的 Prompt 面板），可直接选择使用：

| Prompt 名称 | 用途 | 参数 |
|-------------|------|------|
| `quickstart` | 首次接入引导：连接 → 验证 → 列出设备 | 无 |
| `fly-drone` | 实时飞行控制全流程：控制权 → DRC → 起飞 → 飞行 → 返航 → 清理 | `drone_sn`（必填） |
| `run-wayline` | 航线自动任务：上传 → 创建 → 执行 → 监控 | `dock_sn`（必填） |
| `check-device` | 设备健康检查：状态 → HMS 告警 → 固件 → 诊断 | `device_sn`（必填） |
| `post-flight` | 飞后数据处理：媒体下载 → 三维重建 → 飞行记录归档 | `drone_sn`（必填） |

> **提示**：即使不手动选择 Prompt，AI 在理解你的意图后也会自动遵循对应的最佳实践流程。Prompt 模板的价值在于确保关键步骤（如资源释放、错误处理）不被遗漏。

## 常见问题（FAQ）

### Q: 连接失败，提示 "401 Unauthorized"

**A:** Token 无效或已过期。请从 DJI Cloud API 2 管理控制台重新获取 Token，并更新配置。

### Q: 连接成功但调用工具时提示 "session not found"

**A:** 会话可能已超时断开（默认 30 分钟无操作）。重新发送"连接 DJI Cloud API 2"即可恢复。

### Q: 操作被拒绝，提示 "security level exceeded"

**A:** 你尝试执行的操作超过了平台管理员设置的安全等级上限。请联系管理员调整 `FH_MAX_SECURITY_LEVEL` 或改用低等级操作。

### Q: 飞行指令失败，提示 "control authority not acquired"

**A:** 飞行操作前需要先获取控制权。正常情况下 AI 会自动处理，如果仍然失败，可能是其他 session 持有控制权。等待对方释放或联系管理员。

### Q: 无人机显示 offline，无法操作

**A:** 机场内的无人机在待机时通常是离线状态（断电存储），这是正常现象。只要**机场（Airport/Dock）在线**即可执行起飞等操作。

### Q: 如何在不实际飞行的情况下测试？

**A:** 有两种方式：
1. **dry_run 模式**：所有 L1+ 工具支持 `dry_run=true`，只校验不执行
2. **Mock 模式**：如果平台配置了 `FH_MOCK=true` 的测试环境，所有操作返回模拟数据

### Q: 操作执行后无人机没反应

**A:** 请检查：
1. 设备是否在线（`fh_device_list`）
2. 是否已建立 DRC 链路（`fh_session_info` 查看链路状态）
3. 无人机是否在机场内（需要先起飞）
4. 信号是否正常（查看 OSD 中的 GPS 和链路质量）

### Q: 如何查看操作历史？

**A:** 使用 `fh_flight_record` 查询飞行记录，或使用 `fh_hms` 查询健康告警历史。所有 L1+ 操作都有审计日志。

### Q: 支持同时控制多台无人机吗？

**A:** 当前 MCP Server 单个 session 一次只能控制一台无人机（控制权互斥）。但你可以在释放控制权后切换到另一台无人机。查询和监控操作不受此限制，可以同时查看多台设备状态。

### Q: 调用频率太高被拒绝（429）

**A:** MCP Server 内置限流保护，默认每个 IP 每 60 秒最多 100 次请求。正常交互不会触发。如果批量脚本调用触发了限流，请降低频率或联系管理员调整 `FH_RATE_LIMIT_MAX`。

### Q: 环绕飞行（POI）报错 325003

**A:** 无人机当前位置不能与环绕中心点重叠。将环绕中心设为地面目标（机场、建筑物等），而非无人机自身坐标。如已在目标上方，先用 `fh_flyto` 飞离后再启动 POI。
