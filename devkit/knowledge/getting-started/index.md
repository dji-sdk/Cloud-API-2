# Getting Started

本模块帮助 ISV 从零开始接入 DJI CloudAPI2 SDK。

## 包含内容

| 文档 | 说明 |
|------|------|
| [sdk-setup.md](sdk-setup.md) | SDK 初始化配置、环境要求、Spring Boot 集成模式 |

## 前置条件

- 已获取 DJI CloudAPI2 SDK JAR（`flight-hub-sdk-3.3.7.jar`）
- 已获取平台访问凭证（server address + access token）
- Java 17+ 运行环境
