# 验证命令速查

> 部署各阶段的验证命令。AI 每完成一步引导用户执行对应验证。

## Docker 镜像构建验证

```bash
# 确认镜像存在
docker images | grep flighthub-mcp
# 期望：dji/flighthub-mcp   latest   xxxxx   xx MB

# 检查镜像架构
docker inspect dji/flighthub-mcp:latest --format '{{.Architecture}}'
# 期望：amd64
```

## 容器运行验证

```bash
# 容器状态
docker ps | grep pf-devkit-mcp
# 期望：Up xx seconds (healthy)

# 容器日志（最后 20 行）
docker logs pf-devkit-mcp --tail 20
# 期望：含 "Started FlighthubMcpServerApplication" 且无 ERROR
```

## 健康检查端点

```bash
# Liveness（JVM 存活）
curl -sf http://<host>:8080/pf-devkit/ai-plugin/mcp/health
# 期望：{"status":"UP","timestamp":"..."}

# Readiness（工具注册完成）
curl -sf http://<host>:8080/pf-devkit/ai-plugin/mcp/ready
# 期望：200 OK（启动 15 秒后）

# Status（运维诊断）
curl -sf http://<host>:8080/pf-devkit/ai-plugin/mcp/status | python3 -m json.tool
# 期望：含 version、uptime、toolCount(51)、activeSessions
```

## SSE 流验证

```bash
# 连接 SSE 端点（应收到 event:endpoint 事件）
curl -N \
  -H "Accept: text/event-stream" \
  -H "Authorization: Bearer <FH_SSE_AUTH_TOKEN>" \
  http://<host>:8080/pf-devkit/ai-plugin/mcp/sse

# 期望输出：
# event: endpoint
# data: /pf-devkit/ai-plugin/mcp/message?sessionId=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
#
# :ping
```

> Ctrl+C 退出。收到 `event: endpoint` 即表示 SSE 端点正常。
