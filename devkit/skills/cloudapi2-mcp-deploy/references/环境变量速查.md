# 环境变量速查

> 来源：`mcp/docs/部署指南.md` §6、`mcp/.env.example`。

## 必填（缺失导致启动失败或功能不可用）

| 变量 | 默认 | 说明 | 生成方式 |
|------|------|------|----------|
| `FH_SERVER_ADDRESS` | — | FlightHub 服务器地址（含协议，如 `https://your-server.com`） | 从控制台获取 |
| `FH_ACCESS_TOKEN` | — | 工作空间访问令牌（真实模式必填） | 从 FlightHub 控制台获取 |
| `FH_WORKSPACE_UUID` | — | 工作空间 UUID（真实模式必填） | 从 FlightHub 控制台获取 |
| `FH_SSE_AUTH_TOKEN` | — | SSE 模式客户端鉴权 token（**留空拒绝启动**） | `openssl rand -hex 32` |

## 传输与端口

| 变量 | 默认 | 说明 |
|------|------|------|
| `FH_TRANSPORT` | stdio | `stdio`（本地 IDE）/ `sse`（远程 Docker） |
| `FH_SSE_PORT` | 8080 | SSE 监听端口 |
| `FH_SERVER_PORT` | 443 | FlightHub 服务器端口（占位默认，实际端口以 FlightHub 运维提供为准） |

## 安全

| 变量 | 默认 | 说明 |
|------|------|------|
| `FH_MAX_SECURITY_LEVEL` | 2 | 最大安全等级（0 只读 → 3 紧急停机），生产建议 2 |
| `FH_OPERATOR_TOKEN` | — | L3 操作员 token（仅 `FH_MAX_SECURITY_LEVEL=3` 时需要） |
| `FH_MOCK` | false | Mock 模式，跳过真实 SDK 初始化 |

## 心跳与连接管理

| 变量 | 默认 | 说明 |
|------|------|------|
| `FH_HEARTBEAT_INTERVAL` | 30000 | 心跳广播间隔（ms） |
| `FH_HEARTBEAT_TIMEOUT` | 300 | 空闲超时断连（s） |
| `FH_GRACE_PERIOD` | 60 | 重连宽限期（s） |
| `FH_SESSION_TIMEOUT` | 1800 | 会话超时（s） |

## 限流（SSE 模式）

| 变量 | 默认 | 说明 |
|------|------|------|
| `FH_RATE_LIMIT_MAX` | 100 | 单 IP 每窗口最大请求数 |
| `FH_RATE_LIMIT_WINDOW_SECONDS` | 60 | 限流窗口（s） |
| `FH_RATE_LIMIT_TRUST_PROXY` | false | 是否信任 `X-Forwarded-For`（仅受信反代后启用） |
| `FH_RATE_LIMIT_MAX_KEYS` | 10000 | 最大跟踪 IP 数（防 OOM） |

## 功能开关

| 变量 | 默认 | 说明 |
|------|------|------|
| `FH_COCKPIT_URL` | — | 驾驶舱前端地址，起飞成功后返回监看链接 |
| `FH_CORS_ALLOWED_ORIGINS` | — | CORS 允许源（逗号分隔） |
| `FH_AUDIT_ENABLED` | true | 审计日志 |
| `FH_IDEMPOTENCY_ENABLED` | true | 幂等缓存（防重试重复飞行指令） |
| `FH_IDEMPOTENCY_TTL` | 300 | 幂等缓存 TTL（s） |
| `FH_FAILSAFE_ON_CRASH` | return_home | 无人机崩溃应对策略 |
| `FH_FAILSAFE_DISCONNECT_TIMEOUT` | 60 | 失联超时（s） |

## 系统兼容性

| 变量 | 默认 | 说明 |
|------|------|------|
| `GLIBC_TUNABLES` | — | Ubuntu 26.04+ 必设 `glibc.rtld.execstack=2` |
| `JAVA_OPTS` | `-XX:+UseContainerSupport -XX:MaxRAMPercentage=75.0` | JVM 参数（Docker 默认） |

## deploy.sh 专用变量（`mcp/deploy.env`）

| 变量 | 说明 |
|------|------|
| `REMOTE_HOST` | 远端服务器 IP |
| `REMOTE_USER` | SSH 用户名 |
| `REMOTE_PASS` | SSH 密码（通过 sshpass -e 传递，不落命令行） |
| `REMOTE_SSH_PORT` | SSH 端口（默认 22） |
| `REMOTE_DIR` | 远端 docker-compose.yml 所在目录 |
| `REMOTE_PORT` | 健康检查端口（默认 8080） |
