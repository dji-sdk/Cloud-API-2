# 部署验证命令

> 三形态部署完成后的健康检查与确认步骤。AI 在部署尾声引导用户执行。

## 普通机器

```bash
curl -f http://127.0.0.1:8080/pf-devkit/ai-plugin/skeleton/actuator/health
# {"status":"UP"}
curl -f http://127.0.0.1/          # 前端可达
journalctl -u skeleton -f          # 后端日志无 ERROR
```

## Docker Compose

```bash
docker compose -f skeleton/docker/docker-compose.yml ps
curl -f http://<server-ip>:<BACKEND_PORT>/pf-devkit/ai-plugin/skeleton/actuator/health
# {"status":"UP"}
```

## Kubernetes

```bash
kubectl -n fh-skeleton get pods,svc,ingress
kubectl -n fh-skeleton get sts mysql        # READY 1/1
kubectl -n fh-skeleton port-forward svc/skeleton-backend 8080:8080 &
curl -f http://127.0.0.1:8080/pf-devkit/ai-plugin/skeleton/actuator/health
```

## 验收标准

1. 后端 `actuator/health` 返回 `{"status":"UP"}`
2. 前端页面可访问（登录/注册页正常）
3. 无致命 ERROR 日志
4. （sdk 模式）设备列表可查到真实设备

> 符合以上才宣告部署完成。若健康检查失败 → references/部署排障.md。
