01

平台概述

DJI Cloud API 2 无人机管理平台是基于 DJI Cloud API 2 SDK 构建的全功能无人机运营管理系统，为集成商（独立软件供应商）提供一站式专业机队管理能力。平台涵盖设备接入、实时监控、航线规划、任务调度、媒体管理、空域管控与三维重建等完整业务闭环。

◆核心能力一览

平台将碎片化的无人机运营能力整合为统一的管理视图，让运营人员无需关心底层 SDK 细节，即可完成从设备接入到数据成果的全流程操作。

02

登录与账号管理

平台提供完善的注册、登录与基于角色（RBAC）的权限体系。系统中第一个注册的用户将自动成为管理员（admin），拥有用户管理权限。

◆2.1 登录

访问平台地址后，未登录状态会先展示引导着陆页（欢迎页），点击「登录进入系统」按钮进入登录页面；直接访问受保护页面（如数据看板）时同样会跳转到该着陆页。登录是进入平台所有功能的前提，安全会话通过 JWT 令牌维持。

登录页
1输入用户名
2输入密码（出于安全考虑，密码输入框会掩码显示）
3点击红色「登录」按钮提交

如尚未注册，点击登录表单下方的「创建新账号」即可进入注册页面。

◆2.2 注册账号

注册页

注册页面收集账号基础信息，字段说明如下：

字段是否必填说明
用户名必填3~64 个字符，用于登录。
昵称可选平台内展示的显示名称。
邮箱可选联系方式，仅作记录，平台不提供自助找回密码。
密码必填至少 8 位，建议使用大小写字母 + 数字组合。
确认密码必填需与密码保持一致。

提交注册后进入审核流程：

1提交注册后页面提示「注册成功，请等待管理员审核」，不会自动登录
2新账号状态为待审核（Pending），管理员在「用户管理」页点击 Approve 通过
3审核通过后状态变为已通过（Approved），方可正常登录
4被拒绝（Rejected）的账号无法登录
👑
首个用户自动成为管理员系统部署后，第一个成功注册的用户将被自动授予 admin 角色并直接通过审核，可访问用户管理页面。后续注册用户默认为普通用户（user）。
⚠️
开放注册默认关闭后端配置 FH_USER_REGISTRATION_ENABLED 默认为 false。如注册页提示不可注册，需由运维临时开启注册，或直接通过初始化 SQL / CLI 创建账号。

◆2.3 用户菜单

点击右上角用户头像展开下拉菜单。

用户管理入口
菜单项说明
用户名 / 角色菜单顶部显示当前账号用户名及角色（管理员 / 普通用户）。
用户管理仅管理员可见，进入用户管理页面。
主题色取色器，切换平台主题强调色。
使用说明新标签页打开本文档。
Mock Debug仅在开启调试面板（VITE_MOCK_DEBUG_PANEL=true）时显示。
退出登录退出并返回引导着陆页。

◆2.4 用户管理页面

用户管理页面

管理员可在此页面对所有用户进行管理。

列表字段：

字段说明
ID用户唯一标识。
用户名登录账号，当前登录用户行带「我」标记。
角色管理员（高亮标签）/ 用户。
状态Approved（已通过）/ Pending（待审核）/ Rejected（已拒绝）。
邮箱注册时填写，可为空，空值显示 -。
注册时间账号创建时间。
操作见下方操作表。

操作说明：

操作显示条件说明
Approve仅待审核（Pending）用户审核通过，通过后方可登录。
修改密码仅当前用户行修改自己的密码，需输入旧密码。
Reset Pwd其他用户行管理员直接重置他人密码，仅需新密码。
设为 Admin非自己且当前为普通用户将普通用户提升为管理员。
取消 Admin非自己且当前为管理员撤销管理员权限。
Delete非自己待审核用户表示拒绝注册；已通过用户表示删除账号（不可恢复）。
ℹ️
管理员不能删除或修改自己的角色，避免误操作导致无人可管理。表头右侧「刷新」按钮可重新拉取用户列表。
03

数据看板

数据看板为系统首页，是运营人员进入平台后的第一屏，提供机队运营数据的全局概览，帮助快速掌握整体运行态势。

数据看板首页

◆3.1 左侧 — 资产统计

资产统计面板以卡片形式展示平台核心资产的数量与状态分布：

数据项说明
机场状态空闲 / 作业 / 调试 / 离线的数量及占比。
飞行器在线 / 离线飞行器数量。
中继站中继站数量。
航线总数已创建的航线条数。
人员总数平台注册用户数。
数据成果媒体数、模型数、报告数的汇总。

◆3.2 中央 — 地图视图

卫星影像地图展示所有设备（机场、飞行器）的地理分布位置。设备标记实时更新在线状态，运营人员可快速定位任意设备的地理位置，并直观判断其是否在线。

◆3.3 右侧 — 任务与飞行数据

  • 任务分布 — 柱状图展示计划任务和手飞任务的时间分布。
  • 执行结果 — 折线图展示任务执行 成功 / 挂起 / 失败 的趋势。
  • 飞行数据 — 统计飞行次数、飞行时长、飞行里程。

◆3.4 时间筛选

支持按时间范围切换数据展示，满足不同的运营分析周期，共 6 档：

本周 本月 近一周 近一月 近半年 近一年

04

直播大屏

直播大屏用于实时查看多台设备的视频流画面，适合指挥中心、多机协同等场景，支持多种画面布局与多机同屏监看。

直播大屏

◆4.1 布局设置

根据监看设备数量与屏幕尺寸，可在画面区上方切换多种布局模式：

布局类型可选数量
普通布局1 / 4 / 9 / 16 / 25
L 型布局6 / 8 / 13
包围布局13

◆4.2 画面设置

  • OSD 信息 — 开关切换，在视频画面上叠加飞行参数（高度、速度、坐标等）。
  • 画面显示 — 自适应 / 填充模式，适配不同的视频宽高比。

◆4.3 添加播放器

左侧「添加播放器」面板支持两种方式添加视频源：

1在「输入设备 SN」框中填入 SN 后点击「添加」
2或从下方「在线设备」列表中点选设备卡片直接加入画面

「在线设备」标题右侧的「⟳」按钮可刷新列表；无设备在线时显示「暂无在线设备」。

◆4.4 视频画面操作

每个视频窗口在鼠标悬停时，顶部显示一条悬浮条：左侧为设备 SN 和播放状态（如 playing / error），右侧为「×」关闭按钮，点击可关闭该路画面。

画质、码流、OSD 叠加等参数请在「画面设置」面板中统一调整（见 4.2）。

ℹ️
说明：未分配视频源的窗口显示「无视频」占位；播放失败时窗口内会显示错误信息。

06

驾驶舱

驾驶舱是平台核心功能页面，提供完整的实时飞行监控与操控能力，包括地图轨迹、辅助影像、实时画面与飞行仪表，是执行飞行任务时的「主控台」。

◆6.1 选择设备

进入驾驶舱前需先选择一台在线机场设备，驾驶舱将围绕该设备及其关联飞行器展开监控。

驾驶舱设备列表
  • 左侧列出所有在线机场及其关联飞行器。
  • 显示设备 SN、型号、在线状态。
  • 点击「驾驶舱」按钮进入该设备的实时控制界面。
  • 点击「设备小窗」可快速查看设备监控画面。

◆6.2 飞行监控

驾驶舱页面

驾驶舱页面采用多区域布局，各区域职责如下：

左上 — 地图视图

  • 卫星地图展示设备位置和飞行轨迹。
  • 支持 2D / 3D 视角切换。
  • 显示机场、飞行器、航点等标记。

左下 — 辅助影像

  • 机场摄像头画面（红外 / 可见光）。

右侧 — 主画面

  • 飞行器实时视频画面。
  • 广角 / 变焦镜头切换。
  • 相机参数显示（ISO、快门、光圈等）。

底部 — 飞行仪表

  • 罗盘与航向指示。
  • 速度（SPD）、高度（ALT / ASL / AGL）。
  • 飞行距离、飞行时间。
  • RTK 信号状态、电池电量。

右下 — 操控按钮

飞行操控面板由 SDK 驾驶舱组件内置渲染，具体按钮以实际页面为准。点击左上角「切换设备」可销毁当前驾驶舱并返回设备选择页。

⚠️
高风险操作提示起飞、返航、紧急停止等指令属于高风险操作，执行前请确认周边环境安全。
07

航线编辑器

航线编辑器提供从航线库管理到3D 可视化航线规划的完整能力，支持贴近摄影、面状、航点等多种航线类型，是精细化作业的核心工具。

◆7.1 航线库

航线库列表

航线库页面管理所有已创建的航线文件，列表主要字段如下：

字段说明
复选框、航线名称、类型、航点数、距离、机型、负载、更新时间、操作（编辑）

航线类型（彩色标签，共 7 种）：

  • 航点航线 AI巡逻航线 逐点巡航巡检。
  • 面状航线 带状航线 区域覆盖式测绘。
  • 斜面航线 几何体航线 贴近摄影航线 精细化倾斜摄影建模。

操作按钮：

  • + 创建航线 — 新建航线。
  • 导入 — 导入 KMZ 航线文件。
  • 导出 — 导出选中航线；未勾选时置灰，勾选后按钮显示选中数量。
  • 拼接航线 — 合并多条航线，至少勾选 2 条才可用。
  • 删除 — 批量删除，未勾选时置灰。

支持按机型、负载下拉筛选，按航线名称搜索（占位符「搜索航线名称…」），右侧「⟳」可刷新列表；无数据时显示「暂无航线数据」。

◆7.2 创建新航线

创建航线对话框

点击「+ 创建航线」后弹出配置对话框，按步骤完成：

第 1 步 — 选择航线类型

分类航线类型
巡逻巡检航线航点航线、巡逻航线
测绘航线面状航线、带状航线
精细化测绘航线斜面航线、几何体航线、贴近摄影航线

第 2 步 — 选择飞行器

  • 经纬 M30 系列
  • Mavic 3 行业系列
  • Matrice 3D 系列
  • Matrice 4 行业系列
  • Matrice 4D 系列
  • Matrice 400

第 3 步 — 选择型号

例如：经纬 M30 / 经纬 M30 T。

第 4 步 — 输入航线名称

输入航线名称后点击「确定」进入编辑器。

◆7.3 航线编辑

航线编辑界面

进入航线编辑器后，可在 3D 地图上进行航线规划：

  • 左侧参数面板 — 选择镜头（广角 / 红外）、GSD 分辨率设置（cm / pixel）、相对被摄面距离、安全起飞高度、测区顶部 / 底部高度（ASL）。
  • 地图区域 — 在地图上绘制航线区域，蓝色线条显示规划航线路径，航点标记。
  • 右上 — 测区绘制工具。

◆7.4 贴近摄影流程

贴近摄影流程

贴近摄影航线遵循 4 步流程：

  • 创建粗模 — 开启贴近摄影粗模重建开关，生成粗模。
  • 选择粗模 — 选择目标粗模，调整点云粒度查看。
  • 画测区，生成航线 — 在粗模上框选测绘区域。
  • 通过参数页面调整航线参数。
08

任务管理

任务管理页面展示所有飞行任务及其执行状态，支持任务的创建、执行、暂停 / 取消与轨迹回放，是飞行调度的核心入口。

◆8.1 任务列表

任务管理列表

顶部工具栏：左侧为状态筛选下拉与「共 N 条任务」计数；右侧为「刷新」和「新建任务」。

字段说明

新建任务

AI 助手（Copilot）

平台内置 AI 助手（Copilot），通过自然语言交互提供智能运维能力，让复杂的设备查询、任务下发与数据汇总变得简单直接。

AI 助手 Copilot

◆12.1 入口

点击顶部导航栏右侧「AI 助手」按钮（快捷键 Ctrl + /，macOS 为 Cmd + /），从右侧滑出 Copilot 抽屉；再次按快捷键或点击抽屉右上角「✕」关闭。

抽屉左边缘可拖拽调整宽度。标题栏标识为「Copilot」并带「意图驱动」徽标，右侧依次为「清空对话」和「关闭」按钮。

◆12.2 功能特性

🎯
意图驱动

自然语言描述需求，AI 自动执行操作。

📡
设备查询

询问设备在线状态、型号信息。

📋
任务下发

通过对话创建和管理飞行任务。

📊
数据汇总

自动聚合设备、航线、任务等运营数据。

🛡️
高风险操作确认

涉及写操作的工具调用会先以卡片形式展示工具名并等待用户「批准」或「拒绝」，处理后卡片标记为「已批准」/「已拒绝」。

◆12.3 使用示例

输入框占位符为「用一句话下发任务…」。空对话时展示欢迎页「你好，我是 CloudAPI2 平台 AI 助手」及快捷提问按钮，例如：

  • 查询在线设备列表
  • 查一下今天的告警统计
  • 帮我查一下航线库有哪些航线
  • 查看最近的媒体文件

输入框右侧的麦克风按钮支持语音输入（点击开始录音，再次点击结束，识别结果实时回填到输入框；浏览器不支持语音识别时按钮不可用）。

AI 助手会以结构化表格返回结果，并提供操作建议。

◆12.4 启用条件

AI 助手依赖后端 feature-chat 模块，需满足：

  • 在配置文件中显式开启 — fh.chat.enabled 在 application.yml 中硬编码为 false，且没有环境变量绑定，集成商需直接修改配置文件改为 true（仅设置环境变量无效）。
  • 模型接入 — SPRING_AI_OPENAI_API_KEY（或 SPRING_AI_ANTHROPIC_API_KEY）。
  • MCP 工具通道 — FH_CHAT_MCP_URL（MCP Server 地址）、FH_CHAT_MCP_AUTH_TOKEN（与 MCP Server 的 FH_SSE_AUTH_TOKEN 一致，留空表示不鉴权）。
  • 模型名称（可选） — FH_CHAT_MODEL（主模型）、FH_CHAT_LIGHT_MODEL（L0 只读查询使用的轻量模型）。
