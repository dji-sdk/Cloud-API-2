# FHSDK 集成商培训 Demo — 需求说明

> **用途**：演示集成商如何基于 **FHSDK Java** 自研前后端，完成直播、设备状态、相机数据、帧级位置、地图展示及手动操控。  
> **UI 参考**：同目录 [`reference.png`](./reference.png)（作业台风格，**不要求 1:1 复刻**）。  
> **前端定位**：**集成商自研**，不使用 FHSDK Web SDK / PaaS 组件嵌入。  
> **方案文档**：实现与架构见 [`../0_整体方案.md`](../0_整体方案.md)。

## 1. 项目目标

1. 证明 FHSDK Java 能支撑集成商完成培训范围内的核心能力：设备状态、相机数据、帧级位置、直播、手动操控。
2. 提供一套可供集成商对照学习的完整 Demo（含前后端与文档）。
3. 在地图上直观展示飞机移动、姿态、相机视锥，并对比 **DRC 激光测距** 与 **SEI 光轴几何射线** 两类落点差异。

## 3. 后端功能需求

### 3.1 会话与设备

- 能完成 SDK 初始化与登录。
- 能获取工作空间内设备列表，供前端展示与选择。
- 后续直播、数据订阅、操控等能力均针对**用户选中的设备**执行。

### 3.2 直播

- 能获取并转发当前选中设备的直播画面，供前端播放。
- 播放地址由 Demo 后端统一提供，前端不直接访问 SDK 内部拉流地址。

### 3.3 操控链路

- 支持建立与断开操控链路。
- 链路建立后，方可进行杆量操控、云台拖拽，并接收 **DRC 快激光**；断开后上述操控与 DRC 数据不可用。
- **SEI** 嵌在直播码流中，由开直播（`POST /live/start`）订阅，**不依赖 DRC**。
- **不要求**抢夺或释放飞行控制权。

### 3.4 设备状态数据（慢通道）

后端应持续获取并向业务侧提供以下信息（更新频率较低，用于状态监控与地图飞机模型）：

| 数据 | 用途 |
|------|------|
| 飞机位置 | 地图模型定位 |
| 飞机姿态 | 地图模型姿态 |
| 速度 | 信息条 OSD |
| 电量 | 信息条 OSD |
| 风速 | 信息条 OSD |
| 云台姿态 | 信息条 OSD |
| 机场位置 | 地图机场标记、SEI GND 原点换算 |

> **说明**：本 Demo **不要求** MQTT 慢通道激光测距落点。现场 MQTT OSD 通常不推送激光测距，故不作为验收项；地图测距对比见 [§4.2](#42-地图展示)。

### 3.5 相机操控数据（快通道 / DRC OSD）

建立操控链路后，后端应持续获取并向业务侧提供以下信息（更新频率较高）：

| 数据 | 用途 |
|------|------|
| 激光测距（DRC） | 地图测距落点（设备实测），与 SEI 光轴射线对比 |

### 3.6 帧级位置数据（SEI）

- 能获取高频帧级相机位姿与视场（FOV）信息（**开直播后**从码流 SEI 解析）。
- 能将上述数据提供给前端，用于：
  - 地图相机姿态（坐标轴 / 视锥几何）
  - **光轴射线**：假设画面中心为光轴中心，由 SEI 位姿发出射线与地面（或地形）求交，得到几何落点
  - 后续 FPV 视锥贴地及直播画面贴图（见 [§6](#6-实现阶段)）
- 接受数据之间存在轻微延迟。

### 3.7 手动操控

为在演示中体现飞机移动、云台转动及飞行任务控制，后端应支持以下能力（均依赖操控链路，见 [§6 阶段 D](#6-实现阶段)）：

| 能力 | 说明 |
|------|------|
| 杆量操控 | 接收前端杆量（WASD + 升降 + Q/E 偏航），持续驱动飞机平移 / 升降 / 转向 |
| 云台拖拽 | 接收前端在直播画面上的拖拽，驱动云台俯仰 / 偏航 |
| 一键起飞 | 将飞机置于可手动操控状态（现场已在飞时可省略入口） |
| 急停 | 紧急停止 |
| 返航 / 取消返航 | 触发或取消返航 |

首版已实现：杆量（WASD + R/F 升降 + Q/E 偏航）、云台复位（`resetGimbal`）、直播画面拖拽云台（`stick` 的 `yaw` / `gimbalPitch`）。一键起飞 / 急停 / 返航等待阶段 D 后续交付。

## 4. 前端功能需求

### 4.1 页面布局

参考 [`reference.png`](./reference.png)，页面至少包含：

- **设备列表**：展示可连接设备，支持选择一台；选中后其余功能均作用于该设备。
- **直播区**：主画面，仅播放实时视频；**不做 AR / 视锥等业务叠加**（可显示培训用「画面中心」十字与说明文字，默认可通过顶栏「培训说明」关闭）。
- **地图区**：飞机模型、相机视锥、测距落点对比等空间信息；左下角**地图图例**说明各图层数据来源（培训说明开启时）。
- **遥测对比表**：MQTT / SEI / DRC 三列对比，列头标注典型频率与前置条件。
- **操控区**：杆量、云台拖拽及飞行控制按钮（需已建立操控链路）。
- **培训说明开关**（顶栏）：控制三层数据摘要、图例、画面中心标注、表头频率与脚注；状态持久化至 `localStorage`。

### 4.2 地图展示

- **飞机模型**：根据慢通道位置与姿态实时更新位置、朝向（俯仰 / 横滚 / 偏航）。
- **相机姿态（SEI）**：用 SEI 相机位姿绘制局部坐标系（如 RGB 三轴），便于观察云台变化。
- **测距落点对比**（培训重点）：
  - **DRC 落点**：`drc_camera` 激光测距结果（设备实测），绿点 + 飞机连线。
  - **SEI 光轴落点**：由 SEI 相机位姿沿光轴（+X，画面中心假设）与地面 / 地形求交，另一色落点 + 连线。
  - 对比二者位置差，说明「设备测量」与「几何投影」的差异。
- **FPV 视锥**（分阶段，见 [§6](#6-实现阶段)）：
  - 基于 SEI 位姿 + FOV 内参绘制视锥；
  - 视锥与地面 / 地形交线；
  - 可选：将直播画面纹理贴到地面投影区域（**仅在 Cesium 地图**，不在 `<video>` 上叠 AR）。

### 4.3 直播播放

- 稳定播放实时视频即可。
- **不要求**在视频上叠加 AR、视锥、测距、变焦框等业务元素；培训模式下仅允许非交互的「画面中心」标注（见 [§4.1](#41-页面布局)）。

### 4.4 控制交互

- 所有操控经后端发起，前端不直连设备。
- **杆量操控**：WASD（平移）+ 合理升降键位 + Q/E（偏航），50ms 持续下发；操控时地图模型与视锥应能体现飞机位移。
- **云台拖拽**：在直播画面上按住拖动，驱动云台俯仰 / 偏航；地图视锥 / 光轴落点应随之变化。
- **飞行控制**：一键起飞、急停、返航、取消返航（阶段 D′）。
- 不可用操控应明确禁用或提示（如未建立操控链路时）。

## 5. 数据展示需求

Demo 应能体现三类数据的差异与分工：

| 类型 | 典型频率 | 展示用途 |
|------|----------|----------|
| 设备状态（慢通道 MQTT OSD） | 低频 | 信息条、地图飞机模型位姿、机场位置 |
| 相机操控（DRC OSD） | 较高频 | 激光测距落点（设备实测） |
| 帧级位置（SEI） | 高频 | 相机坐标轴、光轴地面交点、视锥与贴地投影 |

演示时应能说明：

- 低频 MQTT OSD 不适合与画面逐帧对齐；视锥与光轴几何靠 SEI。
- 地图上有两种落点：**DRC 实测** vs **SEI 光轴几何投影**（非 MQTT 慢通道对比）。
- 杆量、云台拖拽及飞行控制均依赖操控链路。

## 7. 验收标准

1. **设备**：能拉取并展示设备列表，选择后后续功能绑定该设备。
2. **直播**：前端能稳定播放实时画面，画面上无任何叠加。
3. **慢通道数据**：信息条有持续更新；地图飞机模型位置 / 姿态随 MQTT OSD 更新。
4. **DRC 测距**：操控链路建立后，DRC 激光落点可见（绿点 + 连线）。
5. **SEI 几何**：SEI 有效时，相机坐标轴可见；光轴地面交点可见，可与 DRC 落点对比（阶段 B）。
6. **视锥**：地图 FPV 视锥及地面投影可见，随 SEI 更新（阶段 C）；贴地为增强项。
7. **手动操控**：杆量可驱动飞机移动（WASD / R/F / Q/E）；直播拖拽可驱动云台；飞行控制按钮见阶段 D′（规划中）。
8. **集成边界**：前端不依赖 FHSDK，仅通过 Demo 后端获取能力与数据。
