## 1. 地图上有什么

连接 DRC 且 SEI 有效时，Cesium 地图上会绘制：

| 元素 | 颜色 | 含义 |
|------|------|------|
| 原点 | 白点（紫边） | SEI 相机光心位置 |
| 光轴 | **红**轴（略长） | 画面中心看的方向（+Z） |
| 画面下 | **绿**轴 | 相机本体系 +Y（图像 v 增大方向） |
| 画面右 | **蓝**轴 | 相机本体系 +X |
| 光轴射线 | 青色线段 | 沿红轴方向延伸到地面/地形 |
| 光轴落点 | 橙色点 | SEI 光轴与地面交点 |
| 光轴落点 | 橙色点 | SEI 光轴与地面交点 |
| DRC 激光 | 绿点 + 连线 | 快通道激光测距（对比用，原点在相机） |
| 视锥地面交线 | 黄色边线 | 与视锥共用 Cesium 远平面角点射线求交，与贴地四边形同一边界 |
| 直播贴地 | 四边形贴图 + 黄边 | WHEP 画面纹理（需已开直播） |

## 2. 相机本体系（红 / 绿 / 蓝）

Demo 采用 **OpenCV 风格右手相机系**，与 SEI NED 欧拉角配合使用：

| 本体系轴 | 地图颜色 | 含义 |
|----------|----------|------|
| **+Z** | 红 | **光轴**：直播画面中心射线方向 |
| **+Y** | 绿 | **画面下**（不是画面上） |
| **+X** | 蓝 | **画面右** |

示意（相机本体系，未旋转前）：

```text
        红 (+Z)  光轴 / 朝前
         ↗
        /
       +----→ 蓝 (+X)  画面右
       |
       ↓
      绿 (+Y)  画面下
```

三根轴始终互相垂直。SEI 每帧更新 `cameraYaw / cameraPitch / cameraRoll` 后，整组轴随相机姿态在世界里旋转。

## 3. 与世界系 NED 的关系

SEI 给出的是 **相机在 NED 世界系下的欧拉角**（单位：度）：

| 字段 | 旋转轴（NED） | 含义 |
|------|---------------|------|
| `cameraYaw` | Down（地） | 光轴在水平面内相对**北向**的朝向 |
| `cameraPitch` | East（东） | 低头 / 抬头 |
| `cameraRoll` | North（北） | 欧拉分解中的 Rx 分量；也参与画面绕光轴倾斜 |

旋转顺序：

```text
R = Rz(yaw) · Ry(pitch) · Rx(roll)
```

Demo 将相机本体系的 +Z（光轴）、+Y、+X 经上述欧拉角变换到 NED，再绘制到地图上。

> **说明**：像素逆投影等 AR 能力在 SDK 侧还有额外的坐标变换步骤；**地图三轴与光轴射线**以 SEI 欧拉角 + 本体系 **+Z 为光轴** 为准。

## 4. 与 MQTT「云台关节角」的区别（易混）

遥测对比表同一行「俯仰 / 横滚」左右两列**名字相似、含义不同**：

| 列 | 数据来源 | 含义 |
|----|----------|------|
| MQTT OSD · 云台 | `gimbal_pitch` / `gimbal_roll` | **云台机械关节角** |
| SEI | `cameraPitch` / `cameraRoll` | **相机在 NED 下的欧拉角** |

### 云台关节角（直觉）

- 俯仰：0° = 朝下，90° = 水平朝前
- 横滚：0° = 不歪

### SEI NED 欧拉角

- 描述的是 **相机光轴/画面** 在空间中的朝向
- **不是**飞机机体横滚
- **不等于**云台 `gimbal_roll` 读数

### 实例：飞机在舱内、相机关机前水平朝前

典型现象：

| 量 | 大致数值 |
|----|----------|
| `cameraYaw` | ~22°（相对北向，合理） |
| `cameraPitch` | ~0° |
| `cameraRoll` | ~90° |
| MQTT `gimbal_pitch` | ~90° |
| MQTT `gimbal_roll` | ~0° |

此时地图三轴通常表现为：

- **红轴**：水平朝前（光轴）
- **绿轴**：竖直朝下（画面下）
- **蓝轴**：水平朝机体右侧（画面右）

`cameraRoll ≈ 90°` **不是说云台横滚 90°**，而是 NED 欧拉分解下，从基准姿态（光轴大致朝下）转到「水平朝前」时，大角度落在 Rx（roll）分量上。地图三轴与直播画面对齐，即说明 SEI 数据可用。

## 5. 数据如何驱动地图

```text
WebSocket SEI 消息
  cameraYaw, cameraPitch, cameraRoll（+ 相机位置）
    ↓
Demo 前端
    ↓
红 / 绿 / 蓝 三轴 + 青色光轴射线 + 橙色地面落点
```

遥测对比表中 SEI 列的俯仰、横滚，即上述 `cameraPitch`、`cameraRoll` 的原始值，与 MQTT 云台角对照时请注意含义不同。

## 6. 常见误解

| 误解 | 正解 |
|------|------|
| SEI 横滚 = 云台横滚 | SEI 是 NED 相机欧拉角，不是关节角 |
| 水平朝前时 SEI pitch 应 ≈ 90° | 应对照 **MQTT 云台俯仰**；SEI 可能是 pitch≈0、roll≈90 |
| 绿轴 = 画面上 | 绿轴 = **+Y = 画面下**（OpenCV 惯例） |
| 表格 pitch/roll 写反了 | 表格透传 SDK 字段；与云台角数值不同属正常 |
| 红轴不对、蓝轴才对 | 光轴在本体系 **+Z**，地图上映射为 **红轴** |
