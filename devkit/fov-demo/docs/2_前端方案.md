## 3. 页面信息架构

与 [需求 §4.1](./requirement/需求说明.md#41-页面布局)、原型页一致：

```text
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏：Demo 标题 · SDK / WS / 直播 / DRC 状态 · 当前设备 SN          │
├──────────┬─────────────────────────────┬─────────────────────────┤
│ 设备列表  │  工具栏 + 直播区（WHEP）      │  Cesium 3D 地图          │
│          │  ①连接WS ②开启直播 ③连接DRC   │  飞机 / 双落点 / 视锥     │
│  可选中   │                             │                         │
│  可取消   ├─────────────────────────────┤                         │
│          │  遥测对比表（OSD / SEI / DRC） │                         │
├──────────┴─────────────────────────────┴─────────────────────────┤
│ 杆量 · 云台 / 飞行控制 · 消息日志                                  │
└──────────────────────────────────────────────────────────────────┘
```

**区域职责**

| 区域 | 数据来源 | 交互 |
|------|----------|------|
| 设备列表 | `GET /devices` | 单击选中；按钮取消选择 |
| 直播 | `POST /live/start` → WHEP | 用户手动开启/关闭；纯播放无叠加 |
| 地图 | WS：`mqtt_osd` / `drc_camera` / `sei` | 飞机模型、DRC 落点、SEI 三轴/光轴/视锥 |
| 遥测表 | WS 各通道 | 只读对比 |
| 杆量 | `POST /control/stick` | WASD 平移 + R/F 升降 + Q/E 偏航；直播区拖拽云台，50ms，需 DRC |
| 云台 / 飞行 | REST 控制接口 | 复位 ✅、拖拽 ✅（stick）；起飞 / 急停 / 返航（阶段 D′） |

## 4. 交互与状态机

与 [整体方案 §5.2](./0_整体方案.md#52-状态机) 对齐：

| 状态 | UI 表现 |
|------|---------|
| 未选设备 | 直播/操控禁用；顶栏无当前 SN |
| 已选设备 | 可点 ①连接 WS、②开启直播、③连接 DRC（**均不自动触发**） |
| WS 已连接 | 顶栏 WS 绿；OSD 日志滚动 |
| 直播已开启 | 顶栏直播绿；`<video>` WHEP 播放 |
| DRC 已连接 | 顶栏 DRC 绿；杆量 / 云台 / 地图双落点可用 |

**关键操作序列**

1. 进入页 → `POST /session/init` → `GET /devices`
2. 点击设备 → `POST /devices/select`
3. 连接 WS → 确认 Payload → 开启直播 → 连接 DRC
4. 取消选择 → 关直播 / 断 DRC / 断 WS → `DELETE /devices/select`

## 7. API 与 WS 对接

- REST：`withCredentials: true`；`baseURL: /api/v1`
- WS：`/api/v1/ws/telemetry`
- WHEP：开发环境 `/oryx` 代理
- 类型与 `0_整体方案` §7.3 对齐

### 7.1 OSD 展示单位

WS 推送为 SDK 原始值；表格 / 信息条展示前在 `utils/formatOsd.ts` 换算：

| 字段 | SDK 单位 | 展示 |
|------|----------|------|
| `windSpeed` | **dm/s**（分米/秒） | 直接展示（例：`17 dm/s`） |
| `horizontalSpeed` / `verticalSpeed` | m/s | 直接展示 |
| `height` / `elevation`（MQTT） | m | 直接展示 |
| SEI `altitude` | **mm**（相对起飞点） | 直接展示（例：`51730 mm`） |
| `attitude*` / `gimbal*` | ° | 直接展示 |
| SEI `latitude` / `longitude` | 整型编码 | × 比例因子 → 度 |
| SEI `fovHorizontal` / `fovVertical` / `curActualFocalLength` | μm | 直接展示；并换算 **HFOV / VFOV / DFOV**（°） |

## 8. Cesium 地图

| 图层 | 数据 | 样式 | 阶段 |
|------|------|------|------|
| 飞机 glTF | `mqtt_osd` location + attitude | 白轮廓模型 | A ✅ |
| 机场 | `mqtt_osd` dockLocation | 青色点 | A ✅ |
| SEI 相机三轴 | `sei` 姿态 | 红 +Z 光轴 / 绿 +Y 下 / 蓝 +X 右 | A ✅ |
| DRC 激光落点 | `drc_camera` | 绿点 + 实线连飞机 | A ✅ |
| SEI 光轴落点 | `sei` 位姿，画面中心=光轴 | 橙点 + 连线 | B ✅ |
| FPV 视锥 | `sei` ar + fov | 青色半透明棱锥 | C ✅ |
| 视锥地面交线 | 四角射线 `globe.pick` / 椭球求交 | 黄色闭合贴地折线（`DynamicGroundClosedPolyline`） | C ✅ |
| 直播贴地 | WHEP + footprint 网格 | `Material(Image)` 三角网格 | C ✅（默认关） |

**地图标题栏开关**

| 开关 | 默认 | 说明 |
|------|------|------|
| Ion 地形 | 关 | 需 `VITE_CESIUM_ION_TOKEN`；开时为 Cesium World Terrain |
| 视频投影 | 关 | 需先开启直播；开时用 `GroundPrimitive` + WHEP 贴地（Classification TERRAIN） |

**说明**

- **地面交线与视频投影解耦**：黄框随视锥 SEI 更新，不依赖「视频投影」开关；贴图仅在开关打开且 WHEP 播放时更新。
- **高度采样**：贴图网格内插点用 `globe.getHeight`（`terrainSurfaceHeight`），不用 `scene.sampleHeight`，避免采到飞机 glTF。
- **椭球模式**：关闭 Ion 地形时，`pickRayGround` 对椭球求交要求 `interval.start ≥ 0`，避免取相机后方交点导致 footprint 失效。
- **不做**：MQTT 慢通道激光落点（现场无推送，见需求说明）。

逆投影参考 `reverse_projection.js`。光轴/ footprint 射线求交见 `seiRaycast.ts`、`seiFrustumFootprint.ts`（远平面角点与 `FrustumGeometry._computeNearFarPlanes` 一致）。

**教程**（`docs/turtorial/`）：

- [SEI相机坐标系说明.md](./turtorial/SEI相机坐标系说明.md) — 三轴含义与 NED
- [Cesium地图动态几何渲染说明.md](./turtorial/Cesium地图动态几何渲染说明.md) — Entity / Primitive 选型、视锥、贴地投影与常见问题

## 9. 直播 WHEP

- 选设备 → 连 WS → **确认 Payload** → `POST /live/start` → WHEP
- **不在 `<video>` 上叠 Canvas**；空间信息仅在 Cesium 地图展示
- 直播区**透明拖拽层**驱动云台（`yaw` / `gimbalPitch`），与底部杆量区并列 ✅

## 11. 培训说明 UI

设计参考 [`requirement/reference.png`](./requirement/reference.png)。顶栏 **「培训说明」** 默认开启，关闭后隐藏下列元素（不影响数据与地图渲染）：

| 组件 | 位置 | 内容 |
|------|------|------|
| `TrainingBanner` | 顶栏下方 | MQTT ~0.5Hz / SEI ~30fps / DRC 激光 三层分工 |
| `VideoCenterHint` | 直播区（仅已开流） | 十字 +「画面中心 = 光轴/激光参考」；非 AR 叠加 |
| `MapLegend` | 地图左上（可收起） | 飞机/三轴（红+Z/绿+Y/蓝+X）/机场/绿橙落点/视锥/黄框/贴地图 |
| 遥测表 caption / 列头频率 / 脚注 | 遥测对比表 | 前置条件、单位说明（mm、dm/s、FOV 等） |

培训话术要点：直播区只看画面；**绿点（DRC 实测）vs 橙点（SEI 几何）** 均对应画面中心，是验收对比重点。
