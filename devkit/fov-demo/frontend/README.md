**依赖环境**：见根目录 [`README`](../README.md) §依赖环境。

方案文档：[`docs/2_前端方案.md`](../docs/2_前端方案.md)

## 打开交互原型

```bash
open prototype/index.html
# 或
npx --yes serve prototype -p 5174
```

浏览器访问后可在页面上：选设备、Connect DRC、WASD、直播区拖拽、查看模拟 WS 消息。
