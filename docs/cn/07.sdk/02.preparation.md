# 准备工作

## 环境依赖
### Java环境要求
- JDK版本: JDK 8 或更高版本
- 操作系统: Linux(ubuntu系统22.04以上)
- CPU 架构: amd64 / x86_64
- 内存要求: 建议至少 4GB 可用内存
### 依赖库
- JNI库: 需要加载对应的本地库文件
- 并发支持: 使用 java.util.concurrent 包进行并发处理

## 使用注意事项
1. **坐标归一化**: 所有坐标都归一化到0-10000范围，便于不同分辨率视频的兼容。
2. **网络字节序**: 多字节数据使用大端序，确保跨平台兼容性。
3. **内存管理**: 建议使用完成后及时释放相关资源。
4. **错误处理**: 编码/解码失败时检查错误码并处理异常情况。
5. **数据完整性**: 确保TLV数据长度正确，避免数据损坏。
6. **性能考虑**: 大量数据时建议分批处理，避免单次处理数据过大。
7. **Java 访问器命名**：模型字段在 Java 侧请使用驼峰访问器（如 getDeviceSn()、setLogLevel()）。本文档中的 Java 示例已与 SDK 中由 SWIG 生成的驼峰包装接口一致；结构体示意里的 snake_case 字段名仍表示与 C++/协议字段的对应关系，调用时请用驼峰方法名。
