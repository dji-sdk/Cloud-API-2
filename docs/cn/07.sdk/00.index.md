# 集成 SDK

FlightHub SDK 基于 C/C++ 进行核心业务开发，通过 JNI 为 Java 端开发者提供本地函数级别的调用体验，让您的后端系统能够轻松实现对机场、飞行器的深度数据交换与复杂任务控制。
