# SDK 简介

应用运行与设备管控底座 FlightHub SDK 基于 C/C++ 进行核心业务开发，通过 JNI 为 Java 端开发者提供本地函数级别的调用体验，让您的后端系统能够轻松实现对机场、飞行器的深度数据交换与复杂任务控制。

---

## 主要功能

|------|------|------|------|
| SDK 初始化与配置 | SDK 生命周期管理 | `FlightHubSDK` | 初始化、关闭、日志级别设置、鉴权配置、版本查询（getVersion/getBuildInfo）、Workspace/Drone/Dock/BaseStation/Relay/RemoteController 实例获取，共 19 个静态方法 |
|  | 工作空间管理 | `Workspace` | 模块化入口，通过子模块获取所有工作空间能力 |
| 设备管理与运维 | 设备管理 | `DeviceManageModule` | 设备列表、详情、改名、解绑、状态监听 |
|  | 固件管理 | `FirmwareManageModule` | 固件升级全流程、进度监听|
|  | 机场控制 | `Dock` + 子模块 | 通过 `getDockOsdModule()`、`getDockControlModule()` 等子模块分类控制 |
|  | 机场控制 | `DockControlModule` | 舱盖/充电/空调/补光灯控制 |
|  | HMS | `HMSModule` / `DeviceHMSModule` | 设备健康管理历史查询与实时告警 |
|  | 日志管理 | `LogManagementModule` | 设备日志查询、报告生成、上传进度监听 |
|  | 设备调试 | `DeviceDebugModule` | 远程调试、参数设置、SIM 切换、换电管理 |
|  | 网络测速 | `NetworkTestModule` | 机场网络测速|
|  | RTK 标定 | `RtkCalibrationModule` | RTK 精度标定|
|  | 中继器控制 | `RelayControlModule` | 中继器 SSID/密码/搜索模式等控制|
|  | 基站 | `BaseStation` | 基站实例入口|
|  | 中继器 | `Relay` | 中继器实例入口|
|  | 遥控器 | `RemoteController` | 遥控器实例入口|

|  | 飞行任务记录 | `FlightTaskRecordModule` | 历史任务记录查询与导出 |
| 直播 | 实时直播 | `LiveModule` | 视频流拉取、SEI 数据订阅（AI/AR/FOV/EIS）|
|  | 直播设备 | `LiveDeviceModule` | 直播可用范围监听、在线观众数查询 |
|  | 直播同步 | `LiveSyncModule` | 直播同步管理|
|  | 自定义 SEI | `CustomSEIModule` | 自定义 SEI 数据编解码 |
|  | 拉流 | `PullStreamModule` | 自定义 WHEP 拉流（获取方式为 `getStream().getPullStreamModule(streamId)`，需传入 streamId 参数）|

|  | 相机控制 | `CameraControlModule` | 拍照/录像/变焦/云台/全景/红外/曝光/白平衡等|

## 模块层次结构

```
FlightHubSDK（入口类，静态方法）
├── initialize / shutdown / getVersion / getBuildInfo / getConfig / isInitialized
├── setWebSocketAuthHeaders / setHttpHeaders / getWebSocketAuthHeaders / getHttpHeaders
│
├── getWorkspaceInstance() → Workspace
│   ├── getDeviceManageModule()         → DeviceManageModule（设备列表/详情/改名/解绑/设备变更监听）
│   ├── getFirmwareManageModule()       → FirmwareManageModule（固件升级全流程）
│   ├── getWaylineManageModule()        → WaylineManageModule（航线库管理）
│   ├── getPsdkResourceModule()         → PsdkResourceModule（PSDK 喊话器资源）
│   ├── getAIBoxModule()               → AIBoxModule（AI Box 应用管理）
│   ├── getAIAlertModule()             → AiAlertModule（AI 智能告警）⭐新增
│   ├── getAIInsideManageModule()      → AIInsideManageModule（机载AI算法管理）⭐新增
│   ├── getElementModule()             → ElementModule（地图元素）⭐新增
│   ├── getFlashLedModule()            → FlashLedModule（频闪灯配置）⭐新增
│   ├── getLiveSyncModule()            → LiveSyncModule（直播同步）⭐新增
│   └── 以下 getter 不变：
│       getFlightTaskModule()          → FlightTaskModule
│       getFlightTaskRecordModule()    → FlightTaskRecordModule
│       getMediaServiceModule()        → MediaServiceModule
│       getSafetyServiceModule()       → SafetyServiceModule
│       getHMSModule()                 → HMSModule
│       getLogManagementModule()       → LogManagementModule
│       getMaintenanceManagementModule() → MaintenanceManagementModule
│       getTerraBuildModule()          → TerraBuildModule
│
├── getDroneInstance(sn) → Drone
│   ├── getCameraControlModule()       → CameraControlModule（相机/拍照/录像/云台/热成像/全景）⭐新增
│   ├── getFlightControlModule()       → FlightControlModule（飞行控制）⭐新增
│   ├── getDrcModule()                 → DrcModule（DRC 链路）⭐新增
│   ├── getDroneOsdModule()            → DroneOsdModule（飞机 OSD 状态）⭐新增
│   ├── getControlAuthModule()         → ControlAuthModule（控制权）⭐新增
│   ├── getFlightSettingsModule()      → FlightSettingsModule（飞行参数）⭐新增
│   ├── getTakeoffModule()             → TakeoffModule（一键起飞）⭐新增
│   ├── getPsdkControlModule()         → PsdkControlModule（PSDK 控制）⭐新增
│   ├── getDeviceHMSModule()           → DeviceHMSModule（HMS 健康管理）⭐新增
│   ├── getDeviceStateModule()         → DeviceStateModule（在线状态）⭐新增
│   ├── getLiveDeviceModule()          → LiveDeviceModule（直播可用范围）⭐新增
│   ├── getAIBoxModule()               → AIBoxModule（AI Box）⭐新增
│   ├── getOnboardAiModule()           → OnboardAiModule（机载AI）⭐新增
│   ├── getDeviceDebugModule()         → DeviceDebugModule（设备调试）⭐搬迁自Workspace
│   └── 以下 getter 不变：
│       getLiveStream(liveInfo)        → LiveModule
│       getFlyToPointModule()          → FlyToPointModule
│       getPoiModule()                 → PoiModule
│       getFlightTaskControlModule()   → FlightTaskControlModule
│
├── getDockInstance(sn) → Dock
│   ├── getDockOsdModule()             → DockOsdModule（机场 OSD 状态）⭐新增
│   ├── getDockControlModule()         → DockControlModule（机场控制）⭐新增
│   ├── getDeviceStateModule()         → DeviceStateModule（在线状态）⭐新增
│   ├── getDeviceHMSModule()           → DeviceHMSModule（HMS 健康管理）⭐新增
│   ├── getLiveDeviceModule()          → LiveDeviceModule（直播可用范围）⭐新增
│   ├── getRtkCalibrationModule()      → RtkCalibrationModule（RTK 标定）⭐新增
│   ├── getNetworkTestModule()         → NetworkTestModule（网络测速）⭐新增
│   ├── getDeviceDebugModule()         → DeviceDebugModule（设备调试）⭐新增
│   └── 以下 getter 不变：
│       getLiveStream(liveInfo)        → LiveModule
│       getFlightTaskControlModule()   → FlightTaskControlModule
│
├── getBaseStationInstance(sn) → BaseStation   ⭐新增
│   ├── getLiveDeviceModule()
│   ├── getRtkCalibrationModule()
│   └── getNetworkTestModule()
│
├── getRelayInstance(sn) → Relay               ⭐新增
│   ├── getRelayControlModule()         → RelayControlModule
│   └── getRtkCalibrationModule()
│
├── getRemoteControllerInstance(sn) → RemoteController  ⭐新增
│
└── getStream() → Stream                       ⭐由 getStreamInstance() 改名
    ├── CustomSEIModule（目标检测框 / 多边形 / 文本叠加 SEI 编解码）
    └── getPullStreamModule(streamId) → PullStreamModule（自定义 WHEP 拉流，注意需传入 streamId 参数，非无参调用）
```

:::caution
SDK 入口类为 `FlightHubSDK`，所有模块实例均通过其静态方法获取。**不要直接调用 `FlightHubSdkManager`**（内部实现类）。
:::

## 适用场景

- 机场自动化运维与远程调度
- 飞行器实时监控与指令下发
- 安防、巡检、测绘、应急等行业应用
- 实时视频直播与 AI 分析数据叠加
- 云端与本地业务深度集成开发
- AI Box / 机载AI 边缘计算应用管理
- 模型重建

## 技术架构

```
Java 业务层（开发者代码）
      ↓ Java API 调用
FlightHubSDK Java 包装层（SWIG 生成）
      ↓ JNI
C/C++ 核心业务层（设备通信 / 任务调度 / 数据处理）
      ↓ MQTT / DRTC / 私有协议
大疆上云 API 2 私有化服务端
      ↓
机场 / 飞行器
```
