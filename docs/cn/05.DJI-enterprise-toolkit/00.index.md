# 大疆行业工具包

**大疆行业工具包**（DJI Enterprise Toolkit）是上云 API 2 面向行业客户提供的一组桌面端辅助工具。

## 1. 工具清单

| 工具 | 程序名称 | 当前版本 | 运行环境 | 文档 |
| --- | --- | --- | --- | --- |
| 航线转换 | `大疆行业工具包-航线转换-v1.1.0.exe` | v1.1.0 | Windows | [使用航线转换工具](./01.wayline-convert-tool.md) |

## 2. 获取方式

全部工具的下载地址见[下载中心](../13.downloads.md)。

## 3. 与上云 API 2 其他能力的关系

| 对比项 | 大疆行业工具包 | 上云 API 2 SDK / 前端组件 |
| --- | --- | --- |
| **形态** | 本地桌面程序 | 服务端 SDK / 可嵌入的前端组件 |
| **部署依赖** | 无，不依赖已部署的上云 API 2 底座 | 需要先完成底座部署 |
| **适用场景** | 临时性、一次性的批量处理与排查 | 集成到自有业务系统中长期使用 |

以航线转换为例：不打算集成 SDK、只想把一批存量航线转到新机型时，用工具包更快；需要让自有平台具备同等能力时，使用上云 API 2 航线编辑器前端组件和 SDK 航线转换接口。
