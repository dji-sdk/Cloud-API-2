# 版本发布记录

## 上云 API 2 V1.1.0 发布记录

### 发布日期

2026.11.05

### 版本概述

V1.1.0 是上云 API 2 的第二个正式版本，在 V1.0.0 的基础上完成三方面演进：

- **底座**：由单机部署升级为集群化高可用部署，新增信创（国产化）软硬件适配与系统级联部署。
- **能力**：SDK 与前端独立组件补齐一批行业高频能力——无人机从地面起飞降落回机场、高速模式切换、超清全景、蛙跳任务（A 起 B 降）、直播云端录制与多协议直播转发、自定义飞行区、告警记录、航线机型转换、航线安全质量管理、三维重建环绕与电力线场景。
- **工具**：设备模拟器能力完善；AI Plugin 扩充 Skill 与 MCP 工具。

> **升级提示：** V1.1.0 进行了国产化与集群化改造，**V1.0.0 无法原地升级到 V1.1.0**，需按「备份数据 → 清理旧版本 → 全新安装 V1.1.0 → 导入数据」的流程迁移。详见 [V1.0.0 迁移至 V1.1.0](./03.deployment/05.migration.md)。

## 上云 API 2 V1.0.0 发布记录

### 发布日期

2026.10.14

### 概述

**上云 API 2** 是面向 DJI 硬件生态的开放 PaaS 产品，以**免费、DJI 原厂能力开放、原生易集成**为设计目标。一体化提供二次开发 SDK、前端独立组件、AI Plugin、开源 demo、设备模拟器等开放能力，助力软件集成商与开发者更高效地基于 DJI 硬件完成二次开发与垂直行业解决方案交付。

### 功能特性

#### 核心能力

- **DaaS（Drone / Dock as a Service）SDK** — 面向对象、协议无感、链式调用，屏蔽底层协议细节；相较上云 API 1 从零封装协议，集成效率显著提升。
- **前端独立组件** — 驾驶舱、航线编辑器、飞行记录、设备管理与运维等开箱即用组件，支持功能配置化与主题定制、自留地开发（定制化）能力，配合 AI Plugin 更快完成二次开发。
- **AI 开发插件** — 提供 AI Plugin 辅助开发，进一步降低二次开发门槛、提升交付效率。
- **开源 demo** — 开发者可参照示例快速理解接口调用逻辑与开发规范，显著缩短上手与交付周期。
- **设备模拟器** — 内置设备模拟器，支持设备虚拟调试，二次开发调试无需强依赖真机。

#### SDK（Java）能力

覆盖设备管理、远程调试、远程操控、实时直播、航线任务、媒体管理、模型重建、AI 识别与告警等场景能力，且持续迭代开放。

| 分类 | 功能 |
|---|---|
| **初始化与配置** | SDK 初始化、SDK 配置、鉴权头注入、生命周期管理等 |
| **设备接入** | 机场和飞行器接入、机场状态监听、云端切换设备的云服务归属等 |
| **远程调试** | 设备远程调试、DRC 链路、控制权管理、飞行记录导出等 |
| **设备管理** | 设备管理、设备在线状态、设备报修维护、固件升级管理、设备日志管理等 |
| **飞行控制** | 飞行控制、一键起飞、飞向目标点、POI 环绕飞行、飞行参数设置、飞机状态监听等 |
| **航线任务** | 航线任务管理、航线任务控制、航线管理等 |
| **直播** | 直播设备管理、实时直播、直播录制、自定义 SEI、相机控制、拉流等 |
| **媒体与数据处理** | 媒体管理、模型管理、模型重建等 |
| **AI 能力** | AI Box、AI 告警、机载 AI 识别等 |
| **其他拓展** | PSDK 控制、PSDK 资源管理、安全服务等 |

#### 前端独立组件

| 组件 | 说明 |
|---|---|
| **驾驶舱**（`FH2.loadCockpit`） | 实时视频直播、飞行状态监控与飞行控制等 |
| **航线编辑**（`WaylineEditor`） | 可视化创建与编辑航线，支持航线拼接、设备拓扑连线等 |
| **航线预览**（`WaylineView`） | 用于快速预览一组航线，支持多航线同时渲染等 |
| **设备管理**（`UranusDeviceManagerApp`） | 设备列表、远程调试、HMS 告警、设备定损与反馈等 |
| **飞行记录**（`FlyDataReplay`） | 飞行历史数据查看与轨迹回放 |
| **直播大屏**（`DJILivePlayer`） | 单路直播、多路直播 |
| **设备小窗**（`FH2.loadDeviceWindow`） | 在页面中查看设备的直播与状态 |

#### AI Plugin

安装到 **Claude Code / CodeBuddy / TRAE** 即可使用，由三部分组成：

- **10 个 Skill** — 提供后端 SDK 集成、前端独立组件、研发问题反馈等 Skill；
- **4 个快捷指令** — 快速生成对应开发代码；
- **MCP Server** — 让 AI Agent 可以访问到对应机场和飞行器的数据和指令。

覆盖后端 SDK 集成开发、前端组件接入、MCP 工具调用、demo 部署、排障诊断等方向。
