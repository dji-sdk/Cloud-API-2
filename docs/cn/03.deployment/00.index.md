# 部署总览

本章说明上云 API 2 应用运行与设备管控底座 V1.1.0 的部署方式。V1.1.0 采用集群化部署，集群底座与业务服务由可视化部署自动安装，支持单节点起步、按需扩容。

> **注意：** 若您当前运行的是 V1.0.0，请不要按本章直接升级。V1.0.0 无法原地升级到 V1.1.0，请先参考 [V1.0.0 迁移至 V1.1.0](./05.migration.md)。

## 部署说明

- **部署约束**：集群各节点建议部署在同一机房、同一网段；上云 API 2、Terra、4G 的许可证须绑定**同一台授权服务器**，V1.1.0 不再支持像 V1.0.0 那样分机安装许可证。
- **负载均衡**：多节点集群需自行配置负载均衡，提供统一访问入口；单节点部署无需负载均衡，直接使用节点 IP 访问。
- **能力扩展按需使用**：[能力扩展](./03.advanced.md) 中的配置项均为可选，根据实际业务需求参考对应章节即可，无需全部执行。
- **AIO 管理后台**：部署完成后，大部分拓展配置均可通过 AIO 管理后台（默认地址：`服务器IP:30888`）进行可视化操作，无需手动修改配置文件。

## V1.0.0 与 V1.1.0 的主要差异

| 维度 | V1.0.0 | V1.1.0 |
|---|---|---|
| 部署架构 | 单机部署 | 集群化部署，支持单节点起步、按需扩容 |
| 软硬件适配 | x86 + Ubuntu Server 22.04 | x86 支持 Ubuntu Server 22.04 / 24.04 LTS；新增信创服务器适配，具体支持清单以发布说明为准 |
| 安装入口 | 可视化部署（端口 40000） | 可视化部署（端口 30888） |
| 许可证 | 可分机安装 | 须绑定同一授权服务器 |
