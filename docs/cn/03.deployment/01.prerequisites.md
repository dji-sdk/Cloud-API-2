# 部署前准备

本文档说明部署上云 API 2 应用运行与设备管控底座前需要完成的准备工作：关键术语、服务器与网络环境要求、客户端与终端设备要求。

V1.1.0 的集群底座与依赖组件由可视化部署在部署过程中自动安装，无需提前手动准备运行环境。

## 术语说明

在使用上云 API 2 前，请先了解以下关键术语，有助于更好地理解后续部署与操作。

| 关键词 | 解释                                                                                                                                          |
|---|---------------------------------------------------------------------------------------------------------------------------------------------|
| **CodeMeter 服务** | CodeMeter 是大疆上云 API 2 许可证申请机制的核心组件，负责在服务器上安装、验证和管理许可证授权。部署前需先在服务器上完成 CodeMeter 服务安装，用于在开发者网站申请与绑定对应的许可证。                                    |
| **Terra 建模** | 「Terra 建模」即上云 API 2 软件中依赖大疆智图（Terra）建模引擎开发的私有版建模服务。                                                                                         |
| **4G 增强图传** | 依托 DJI Cellular 模块接入 4G 网络，支持联网、网络 RTK；在原图传受干扰遮挡时协同备份，提升图传可靠性。                                   |
| **集群底座** | V1.1.0 起采用的集群化基础设施，由安装器自动部署，负责容器编排与服务调度。                                                                                                   |
| **信创服务器** | 采用国产化 CPU 与国产化操作系统的服务器。                                        |
| **首节点** | 完成首次部署的第一台服务器，也是后续扩容集群的起点。                                                                                                                  |
| **授权节点** | 导入并绑定许可证的服务器，是首节点部署的前提。                                                                                                                     |
| **VIP（虚拟 IP）** | 多节点场景下，负载均衡对外提供的统一访问入口。                                                                                                                     |
| **Pod 网段 / Service 网段** | 集群内部容器网络使用的 IP 段，不能与现有网络冲突。                                                                                                                 |
| **AIO 管理后台** | 用于管理私有化服务的可视化后台，提供配置、集群管理、4G 增强图传与 Terra 建模服务开通等能力。                                                                                                        |
| **MBTiles** | 一种用于存储地图瓦片的文件格式，允许将地图数据打包为单个文件，便于分发和使用。                                                                                                     |
| **XYZ 格式地图瓦片** | 一种基于瓦片的地图数据组织方式，通过 X、Y、Z 三个坐标来索引地图瓦片，实现灵活的地图浏览。                                                                                             |
| **NTP 服务** | 即网络时间协议（Network Time Protocol）服务，是一种用于同步计算机时钟的网络服务。它允许计算机客户端与服务器进行时间同步，以确保时间的准确性。NTP 是互联网上最广泛使用的协议之一，用于同步计算机系统的时间。                          |
| **Docker** | Docker 是一个开源的应用容器引擎，它允许开发者将应用及其依赖打包到一个轻量级、可移植的容器中，然后发布到任何支持 Docker 的机器上。容器是一个轻量级、可执行的软件包，它将代码和环境封装起来，使得应用可以在几乎任何地方以相同的方式运行，从开发环境到生产环境的无缝迁移。 |
| **EMQX** | 一种高性能的分布式消息中间件，支持多种物联网协议，用于处理设备间的实时消息传递。                                                                                                    |
| **自签证书** | 由组织或个人自行签发的 SSL / TLS 证书，用于网站或服务的加密传输，但未由公认的证书颁发机构签发，可能不被所有客户端信任。                                                                           |

## 服务器环境准备

> **说明：** 本次部署包含三个服务：**上云 API 2 平台**、**Terra 建模服务**、**4G 增强图传服务**，以下要求已将三个服务合并列出，请按需参考。Terra 建模与 4G 增强图传需在部署完成后，于 AIO 管理后台「增值服务」中开通。

### 服务器配置要求

上云 API 2 平台支持标准 x86 服务器与信创服务器，以下各类服务器的推荐配置均针对**单个节点**，请根据机场数量和业务负载规划每个节点的 CPU、内存、数据盘及网络资源。

**1）标准 x86 服务器：**

| 配置项 | 推荐配置（单节点） | 说明 |
|---|---|---|
| CPU 核数 | 16 核 | 可根据实际业务负载调整 |
| 内存 | 64 GB | 可根据实际业务负载调整 |
| 数据盘 | 1000 GB | 使用 SSD，容量按实际数据量调整 |
| 网络 | 局域网部署时，每台机场到路由器的连接速率不低于 100Mbps | 每台机场开启两路直播时约需 5Mbps 带宽；接入更多设备时，请按比例增加总带宽 |

**2）信创 C86 服务器：**

| 配置项 | 推荐配置（单节点） | 说明 |
|---|---|---|
| CPU 核数 | 16 核 | 仅支持海光（Hygon）C86 系列 CPU；核数可按实际业务负载调整 |
| 内存 | 64 GB | 可根据实际业务负载调整 |
| 数据盘 | 1000 GB | 使用 SSD，容量按实际数据量调整 |
| 网络 | 局域网部署时，每台机场到路由器的连接速率不低于 100Mbps | 每台机场开启两路直播时约需 5Mbps 带宽；接入更多设备时，请按比例增加总带宽 |

**3）信创 ARM 服务器：**

| 配置项 | 推荐配置（单节点） | 说明 |
|---|---|---|
| CPU 核数 | 16 核 | 仅支持采用 AArch64 指令集的国产 CPU（如鲲鹏）；核数可按实际业务负载调整 |
| 内存 | 64 GB | 可根据实际业务负载调整 |
| 数据盘 | 1000 GB | 使用 SSD，容量按实际数据量调整 |
| 网络 | 局域网部署时，每台机场到路由器的连接速率不低于 100Mbps | 每台机场开启两路直播时约需 5Mbps 带宽；接入更多设备时，请按比例增加总带宽 |

> **说明：**
> - 数据盘须使用 SSD
> - 如果公网部署，需要固定公网 IP，带宽不低于 100Mbps 稳定且上下行对等的网络环境
> - 基础推荐配置可支持约 20 台机场同时在线；约 50 台机场的单节点场景，建议配置 32 核 CPU 和 128 GB 内存，数据盘容量按实际数据量规划
> - 多节点集群可按机场总量分摊到各节点估算
> - 信创硬件的具体适配清单以发布说明为准

### 依赖组件

集群底座及依赖组件由安装器在部署过程中自动安装（「准备系统环境」「安装集群底座」阶段），**无需预装 Docker、Docker Compose 等第三方容器组件**。V1.0.0 中「需自行准备 Docker 环境并满足最低版本要求」的约束在 V1.1.0 已不再适用。

安装器会在「环境检查」阶段检查操作系统、基础资源、内核参数、网络、依赖包及历史残留，请按页面提示处理告警和异常项；若服务器上存在历史部署残留，请按「残留检测」的提示清理后再继续。详情参考 [开始部署](./02.installation.md) 章节「1.2 环境检查」。

### 时间同步

| 项 | 要求 |
|---|---|
| 服务器时间 | 请确保各节点系统时间准确，且集群内各节点时间保持一致 |
| 终端时间 | 建议浏览器所在终端与服务器的时间差不超过 30 秒；误差过大时，地图、高程等数据上传会提示「网络异常或路径权限缺失」 |
