# 部署前准备

本文档说明部署上云 API 2 应用运行与设备管控底座前需要完成的准备工作：关键术语、服务器与网络环境要求、终端设备固件版本要求，以及 Docker 环境安装。

## 术语说明

在使用上云 API 2 前，请先了解以下关键术语，有助于更好地理解后续部署与操作。

| 关键词 | 解释                                                                                                                                          |
|---|---------------------------------------------------------------------------------------------------------------------------------------------|
| **CodeMeter 服务** | CodeMeter 是大疆上云 API 2 许可证申请机制的核心组件，负责在服务器上安装、验证和管理许可证授权。部署前需先在服务器上完成 CodeMeter 服务安装，用于在开发者网站申请与绑定对应的许可证。                                    |
| **Terra 建模** | 「Terra 建模」即上云 API 2 软件中依赖大疆智图（Terra）建模引擎开发的私有版建模服务。                                                                                         |
| **MBTiles** | 一种用于存储地图瓦片的文件格式，允许将地图数据打包为单个文件，便于分发和使用。                                                                                                     |
| **XYZ 格式地图瓦片** | 一种基于瓦片的地图数据组织方式，通过 X、Y、Z 三个坐标来索引地图瓦片，实现灵活的地图浏览。                                                                                             |
| **NTP 服务** | 即网络时间协议（Network Time Protocol）服务，是一种用于同步计算机时钟的网络服务。它允许计算机客户端与服务器进行时间同步，以确保时间的准确性。NTP 是互联网上最广泛使用的协议之一，用于同步计算机系统的时间。                          |
| **Docker** | Docker 是一个开源的应用容器引擎，它允许开发者将应用及其依赖打包到一个轻量级、可移植的容器中，然后发布到任何支持 Docker 的机器上。容器是一个轻量级、可执行的软件包，它将代码和环境封装起来，使得应用可以在几乎任何地方以相同的方式运行，从开发环境到生产环境的无缝迁移。 |
| **EMQX** | 一种高性能的分布式消息中间件，支持多种物联网协议，用于处理设备间的实时消息传递。                                                                                                    |
| **自签证书** | 由组织或个人自行签发的 SSL / TLS 证书，用于网站或服务的加密传输，但未由公认的证书颁发机构签发，可能不被所有客户端信任。                                                                           |

## 服务器环境准备

> **说明：** 本次部署包含三个服务：**上云 API 2 平台**、**Terra 建模服务器**、**4G 增强图传服务**，以下要求已将三个服务合并列出，请按需参考。

### 服务器配置要求

**上云 API 2 平台服务器配置要求：**

| 配置项 | 推荐配置                           | 说明 |
|---|--------------------------------|---|
| CPU 核数 | 8C                             | 可根据实际情况调整 |
| 内存 | 64 GB                          | 可根据实际情况调整 |
| 数据盘 | 2000 GB                        | 可根据实际情况调整 |
| 网络 | 纯局域网下，每台机场连接到路由器的网速不低于 100Mbps | 每台机场开启两路直播时，大概需要 5Mbps 带宽，支持更多设备需要按比例增加网络带宽 |

> **说明：**
> - 数据盘需要 SSD
> - 如果公网部署，需要固定公网 IP，带宽不低于 100Mbps 稳定且上下行对等的网络环境
> - 此推荐配置经过性能压测，基本可以支持 20 台左右机场同时在线，如果需要同时绑定更多机场使用，请按需增加配置，例如 50 台左右机场，建议使用 16 核、64G 内存的配置。

**Terra 建模服务器配置要求：**

| 配置项 | 推荐配置                         | 说明 |
|---|------------------------------|---|
| CPU | 8C                           | 可根据实际情况调整 |
| 内存 | 64GB 及以上                     | 可根据实际情况调整 |
| 硬盘 | SSD：200GB Free（更佳）           | 可根据实际情况调整 |
| GPU | 推荐使用计算能力在 6.1 及以上的 NVIDIA 显卡 | - |
| 显存（VRAM） | 4GB 及以上                      | - |

**4G 图传增强服务器配置要求：**

[4G 增强图传服务部署](https://terra-1-g.djicdn.com/fee90c2e03e04e8da67ea6f56365fc76/SDK%20%E6%96%87%E6%A1%A3/4G%20Private/4G%20%E7%A7%81%E6%9C%89%E5%8C%96%E5%A2%9E%E5%BC%BA%E5%9B%BE%E4%BC%A0%E6%9C%8D%E5%8A%A1%E9%83%A8%E7%BD%B2%E6%89%8B%E5%86%8C.pdf) 可与上云 API 2 部署在同一台服务器，也可单独部署在独立服务器。若单独部署，需确保与上云 API 2 服务器网络互通。

## Docker 安装

上云 API 2 安装包中内置了 Docker 部署工具，您可以使用该工具快速部署 Docker 环境。若自动安装失败，需根据服务器实际环境自行部署。

工具目录：`上云 API 2 安装包解压目录/tool/docker`

> **注意：** 如果您的服务器已经安装部署 Docker 且版本不是 27.2.0，请先执行以下命令卸载原有 Docker，再进行安装：
> ```bash
> bash ./uninstall_docker.sh
> ```

**安装步骤：**

1. **进入 Docker 工具目录**：进入安装包解压目录，找到 docker 工具目录。

   ```bash
   # 进入安装包目录
   root@dji:~/dji# cd fh2-privatization-install-packages/

   # 查看目录内容
   root@dji:~/dji/fh2-privatization-install-packages# ls
   checksum.json  checksum.sig  env  fh2-privatization-image.tar.gz  images  InstallLicense.sh  package-info  setuptools  tool

   # 进入 tool 目录
   root@dji:~/dji/fh2-privatization-install-packages# cd tool

   # 查看工具列表
   root@dji:~/dji/fh2-privatization-install-packages/tool# ls
   docker  elevation  helm  k3s  map  system_management  traefik
   ```

2. **执行 Docker 安装脚本**：进入 docker 目录并执行安装脚本。

   ```bash
   root@dji:~/dji/fh2-privatization-install-packages/tool# cd docker

   root@dji:~/dji/fh2-privatization-install-packages/tool/docker# ls
   clean_docker.sh  docker-official-package-27.2.0.tgz  install_docker.sh  uninstall_docker.sh

   root@dji:~/dji/fh2-privatization-install-packages/tool/docker# bash ./install_docker.sh
   ```
