# 申请许可证

在使用上云 API 2 之前，您需要先完成许可证申请。整个流程简单快捷，只需在大疆开发者网站在线提交申请，我们的团队会尽快为您完成审批并将证书发送至您的邮箱。

---

## 前提条件
**登录/注册大疆开发者账号**

- 访问[大疆开发者平台官网](https://developer.dji.com/)。
- 点击页面右上角的账户图标，选择 **登录** 或 **注册** 大疆账号。

<img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step1-login.png" alt="登录或注册大疆开发者账号" width="720">

**申请成为大疆开发者**

- 登录大疆开发者平台官网，进入 **生态开发 -> 上云 API 2**。
- 首次进入该板块的用户，平台会提示您申请成为大疆开发者。请点击 **确认** 即可成为开发者。
- 按页面表单的引导，填写您的开发者基本信息（姓氏、名字、国家/地区、城市、所属行业、从业年限及对无人机了解程度等），提交后系统将进行自动审核。

<img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step2-developer-apply-v2.png" alt="申请成为大疆开发者" width="720">

---

## 申请步骤
1. 登录大疆开发者平台官网，进入 **生态开发 -> 上云 API 2**，选择 **申请许可证**，进入 **许可证申请** 页面。

2. **补充许可证申请信息**，按照页面引导填写相关信息如许可证用途、公司名称、公司简介、平台名称、解决方案概述、使用地区等。

   <img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step3-license-apply.png" alt="填写许可证申请信息" width="720">

::: tip 申请小提示
为帮助我们更快处理您的申请，建议您在提交时一次性提供完整信息：
- **公司名称**：请务必填写官方注册全称，避免使用简称或缩写，以便快速核实企业身份。
- **平台名称**：您的集成项目平台或系统平台名称，平台名称请精确到全称，确保与实际部署和管理环境一致。
- **解决方案**：清晰、简要地描述您的集成场景和业务落地方案，有助于提高审批时效。
:::

3. **提交申请**，等待审核，申请结果将通知到您在 DJI 开发者平台账号关联的邮箱
4. **查收邮件**，审批通过后，开发者平台将自动发送通知邮件至您注册的开发者邮箱，邮件中会包含许可证 **激活码**。

   <img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step4-email-notification-v2.png" alt="查收邮件获取激活码" width="720">

5. **创建许可证**
   - 登录大疆开发者平台官网，进入 **生态开发 -> 上云 API 2 -> 申请许可证**。
   - 找到 **许可证工具**，点击 **创建许可证**。
   - 填写第 4 步获取到的 **激活码** 并确认详情无误后，设置 **证书别名**，完成手机号二次安全验证，最后点击 **创建证书** 完成创建。

   <img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step5-create-license-1.png" alt="创建许可证-许可证工具" width="720">
   <img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step5-create-license-2-v2.png" alt="创建许可证-填写激活码" width="720">
   <img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step5-create-license-3.png" alt="创建许可证-完成创建" width="720">

6. **导出许可证文件**，在创建许可证页面中，您可以下载您的专属许可证证书文件。

   <img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step6-export-license.png" alt="导出许可证" width="720">

7. **获取上云 API 2 底座安装包**，在创建许可证页面中，您可以一并下载对应版本的上云 API 2 应用运行与设备管控底座镜像安装包。

   <img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step7-download-package.png" alt="获取底座安装包" width="720">

8. 如需重新下载证书或获取历史版本安装包，可随时返回 **大疆开发者平台官网 -> 生态开发 -> 上云 API 2 -> 申请许可证 -> 历史记录** 页面，按类型（许可证 / 全量升级包）查看，可点击**下载** 或者查看**详情**。

   <img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step8-history.png" alt="历史记录页面" width="720">

## 许可证的使用
许可证成功下载后，您可以开始部署安装上云 API 2 应用运行与设备管控底座，根据可视化部署界面引导，导入许可证文件即可。

<img src="https://terra-1-g.djicdn.com/4670436537e14b5c822b1c7f97b8aac9/es320-kb/cloud-api-2-tutorial/apply-license/step5-activate.png" alt="上传并激活平台" width="720">
