# 驾驶舱模块化配置

驾驶舱（Cockpit）支持通过 `cockpitConfig` 参数精细控制各模块的显隐、子功能开关、自定义按钮注入和布局比例。本文档详述所有可配置字段。

接入前请先完成 [驾驶舱与设备小窗](./01.cockpit.md) 的基本集成。

## 1. 概述

驾驶舱由 5 个顶层模块组成：

| 模块 ID | 名称 | 说明 |
|---------|------|------|
| `topBar` | 顶栏 | 功能入口按钮组（设备列表、告警、航线等） |
| `mainLive` | 主视频区 | 主相机直播画面 + 飞行操控 |
| `subLive` | 辅视频区 | 机场直播 / 遥控器直播 / AI 链接 |
| `map` | 地图 | 飞行地图 |
| `deviceList` | 设备列表 | 设备卡片与管理操作 ⚠️ **当前阶段默认隐藏**，在后续版本中会持续开放 |

通过 `CockpitConfig` 可以：
- **整体显隐某个模块**（`visible: false`）
- **开关模块内的子功能**（`features.*`）
- **注入您的自定义按钮**（`customButtons`，支持图标、跳转 URL 和回调）

**缺省全开原则**：未配置的字段保持默认打开，只有显式设为 `false` / `{ visible: false }` 才会关闭对应功能。

:::tip
**当前阶段例外**：`deviceList`（设备列表）模块当前默认隐藏，不适用缺省全开原则；相关功能在后续版本中会持续开放，届时无需修改您的调用代码。
:::

---

## 2. 如何传入配置

### 2.1 加载时传入

```js
window.FH2.loadCockpit('cockpit-container', {
  gateway_sn: 'YOUR_GATEWAY_SN',
  drone_sn: 'YOUR_DRONE_SN',
  map: true,
  cockpitConfig: {
    modules: {
      deviceList: { visible: false },   // 设备列表模块（默认隐藏，无需显式配置）
      topBar: {
        features: { wayline: false }    // 隐藏顶栏航线入口
      }
    }
  }
})
```

### 2.2 运行时动态更新

驾驶舱已挂载后，可随时通过 `FH2.setCockpitConfig` 推送新配置，UI 即时响应：

```js
window.FH2.setCockpitConfig({
  modules: {
    mainLive: {
      features: {
        leftToolbar: { visible: false }   // 动态隐藏 footer 竖向工具栏（视觉最左）
      }
    }
  }
})
```

:::tip
每次调用会与默认配置做 explicit-only 深度合并（只覆盖显式提供的字段，未提供字段恢复默认值）。若您需要"持久关闭某功能"，每次 `setCockpitConfig` 均需带上该字段。
:::

## 3. 顶层结构 - CockpitConfig

```ts
interface CockpitConfig {
  modules?: {
    topBar?:      ModuleConfig & { features?: TopBarFeatures }
    mainLive?:    ModuleConfig & { features?: MainLiveFeatures }
    subLive?:     ModuleConfig & { features?: SubLiveFeatures }
    map?:         ModuleConfig & { features?: MapFeatures }
    deviceList?:  ModuleConfig & { features?: DeviceListFeatures }   // ⚠️ 默认隐藏，在后续版本中会持续开放
  }
  layout?:     LayoutConfig      // 布局配置
  theme?:      ThemeConfig       // 主题 token 覆盖（预留，当前版本未生效）
  extensions?: ExtensionConfig[] // 自定义插件扩展位（预留，当前版本未生效）
  liveScreen?: LiveScreenConfig  // N 路直播大屏（预留，当前版本未生效）
  waylinePlanUrl?: string   // 您的航线库/飞行任务创建页面地址（非必传）
  cameraAuthVerifyUrl?: string  // 您的外接摄像头验密页面地址（非必传）
}
```

### 模块通用配置 - ModuleConfig

```ts
interface ModuleConfig {
  visible?:  boolean   // 是否显示整个模块，默认 true
  gridCols?: number    // 网格列数（grid 布局时生效），默认 1
}
```

## 4. 各模块字段详解 - features

### 4.1 顶栏功能入口 - topBar

```ts
interface TopBarFeatures {
  deviceList?:    boolean                // 设备列表入口，默认 true ⚠️ 该入口默认隐藏（随 deviceList 模块在后续版本中持续开放），当前配置无可见效果
  alertRecord?:   boolean                // 告警记录，默认 true
  relayTask?:     boolean                // 任务接力，默认 true
  wayline?:       boolean                // 航线规划入口，默认 true
  droneStatus?:   boolean                // 飞机状态遥测条（延迟/图传/RTK/电量），默认 true
  layout?:        boolean                // 布局切换，默认 true（后续版本开放）
  shortcutKey?:   boolean                // 快捷键说明，默认 true（后续版本开放）
  settings?:      boolean                // 设置入口，默认 true（后续版本开放）
  customButtons?: CockpitCustomButton[]  // 您的自定义按钮，渲染于顶栏右侧，默认 []
}
```

**示例：关闭告警记录、注入一个自定义按钮**

```js
window.FH2.setCockpitConfig({
  modules: {
    topBar: {
      features: {
        alertRecord: false,
        customButtons: [
          {
            id: 'my-help',
            name: '帮助',
            tips: '打开帮助中心',
            iconUrl: 'https://cdn.example.com/icons/help.png',
            forwardUrl: 'https://help.example.com'
          }
        ]
      }
    }
  }
})
```

> **（后续版本开放）** 标注的字段已在 type 中定义，但对应 UI 尚未开放；当前设置会被忽略，UI 始终显示。

---

### 4.2 主视频区 - mainLive

:::tip
`mainLive.features` 的子功能值是 **`{ visible?: boolean }` 对象**，而非直接布尔，与 `topBar` 不同。
:::

```ts
interface MainLiveFeatures {
  leftToolbar?:    FeatureToggle           // footer 竖向工具栏（云台/激光/AI/灯光，视觉最左），默认可见
  rightToolbar?:   FeatureToggle           // 相机参数/镜头/红外叠加层，默认可见
  flightControls?: FeatureToggle           // 飞行操控扩展区（右下角起飞/急停等），默认可见
  bottomLeftInfo?: FeatureToggle           // 左下角设备信息，默认可见
  overlay?:        FeatureToggle           // 画面叠加层（HUD 信息），默认可见
  gimbalTools?:    FeatureToggle           // 云台工具组（云台/变焦/激光/IR/AI/PSDK），默认可见（后续版本开放）
  lightMode?:      FeatureToggle           // 灯光/特殊模式组（降落伞/爆闪灯等），默认可见（后续版本开放）
  footerItems?: {                          // footer(leftToolbar 区) 逐项显隐；未配置的 key 默认全开
    gimbalSet?:       boolean              // 云台设置
    mouseFirstAngle?: boolean              // 鼠标优先角度
    spotOn?:          boolean              // 一键指点
    multiPayload?:    boolean              // 多负载控制
    laser?:           boolean              // 激光打点
    rng?:             boolean              // 激光测距（RNG）
    irThermometer?:   boolean              // 红外区域测温
    ai?:              boolean              // AI 目标识别 / 智能跟踪
    aiSearch?:        boolean              // AI 大模型搜索
    ea700?:           boolean              // 妙算 3（EA700）
    psdk?:            boolean              // PSDK 入口
    parachute?:       boolean              // 降落伞
    ar?:              boolean              // AR 投射
    flashLed?:        boolean              // 爆闪灯
    nightLight?:      boolean              // 夜航灯
    stealthMode?:     boolean              // 隐蔽模式
    fts?:             boolean              // 飞行终止系统（FTS）
    customButtons?:   CockpitCustomButton[] // 您的自定义按钮，渲染于 footer(leftToolbar 区)，默认 []
  }                                        // 最终可见 = 组开关(gimbalTools/lightMode) && 该 item && 设备能力
}

// FeatureToggle 类型
interface FeatureToggle {
  visible?: boolean   // 是否可见，默认 true
}
```

**示例：隐藏飞行操控区，注入一个自定义按钮**

```js
window.FH2.setCockpitConfig({
  modules: {
    mainLive: {
      features: {
        flightControls: { visible: false },
        footerItems: {
          customButtons: [
            {
              id: 'mark-point',
              name: '标注',
              tips: '在地图上标注当前位置',
              iconUrl: 'https://cdn.example.com/icons/pin.png',
              cb: function () {
                // 触发您的自定义标注逻辑
                myApp.markCurrentDronePosition()
              }
            }
          ]
        }
      }
    }
  }
})
```

### 4.5 设备列表 - deviceList

:::tip
**默认隐藏**：设备列表模块默认不展示，相关功能在后续版本中会持续开放。在此之前：
- 无需（也不建议）显式配置 `modules.deviceList.visible: true` 强行打开；
- 下方 `features` 子功能配置写入后会被 merge 进配置，但因模块整体隐藏而无可见效果；
- 模块开放后，本节配置无需修改您的调用代码即可生效。
:::

```ts
interface DeviceListFeatures {
  deviceCard?:      boolean   // 设备卡片，默认 true
  addRemoveDevice?: boolean   // 添加/移除设备按钮，默认 true
  filter?:          boolean   // 过滤，默认 true（后续版本开放）
  sort?:            boolean   // 排序，默认 true（后续版本开放）
}
```

**示例：隐藏整个设备列表，或仅隐藏加减设备按钮（模块开放后生效）**

```js
// 整体隐藏
window.FH2.setCockpitConfig({
  modules: { deviceList: { visible: false } }
})

// 仅隐藏加减设备（只读模式）
window.FH2.setCockpitConfig({
  modules: {
    deviceList: {
      features: { addRemoveDevice: false }
    }
  }
})
```

## 5. 自定义按钮

自定义按钮目前支持注入到两处：
- **TopBar**：`modules.topBar.features.customButtons`，渲染于顶栏右侧
- **MainLive footer(leftToolbar 区)**：`modules.mainLive.features.footerItems.customButtons`，渲染于 footer(leftToolbar 区)

```ts
interface CockpitCustomButton {
  id:          string       // 必填。按钮唯一标识（同一区域 id 不可重复）
  name:        string       // 必填。按钮名称（显示于图标下方或 Tooltip 中）
  tips?:       string       // 可选。鼠标 hover 时的提示文字
  iconUrl?:    string       // 可选。图标图片 URL；缺省时显示 name 首字
  forwardUrl?: string       // 可选。点击后跳转的 URL（仅支持 http/https）
  cb?:         () => void   // 可选。点击回调函数
}
```

**点击行为规则：**
1. `forwardUrl` 非空 → 先 `window.open(forwardUrl, '_blank', 'noopener,noreferrer')` 跳转
2. `cb` 非空 → 执行回调（与 `forwardUrl` 不互斥，两者都配置时均会触发）
3. 两者均为空 → 点击无效果（按钮仍可见）

:::tip
`cb` 是函数，无法写入 JSON 字符串。若您使用 `setCockpitConfig`（JSON 传递），只能配置 `forwardUrl`；需要回调的按钮请在 `loadCockpit` 时通过您的代码传入。
:::

## 6. 布局配置 - layout

```ts
interface LayoutConfig {
  mode?:            'splitpanes' | 'grid'   // 布局模式，默认 'splitpanes'
  splitRatios?: {
    primary?:   number   // 主区域宽度比例（0-100），默认 70
    secondary?: number   // 辅区域宽度比例（0-100），默认 30
    map?:       number   // 地图高度比例（0-100），默认 55
    subLive?:   number   // 辅视频高度比例（0-100），默认 45
  }
  defaultMainView?: 'main' | 'map' | 'sub_live'   // 默认主视图，默认 'main'
}
```

**示例：调整主视频区宽度比例为 80%**

```js
window.FH2.setCockpitConfig({
  layout: {
    splitRatios: { primary: 80, secondary: 20 }
  }
})
```

## 7. 航线库地址 - waylinePlanUrl

`waylinePlanUrl` 是 **CockpitConfig 顶层可选字段**（与 `layout`、`theme`、`liveScreen` 同级，非 `modules` 内部），用于指定**您的航线库 / 飞行任务创建页面**地址。

**用途：** 当您点击顶栏航线入口（`topBar.features.wayline`）确认跳转时，驾驶舱的 `openPlan` 会读取该字段决定跳转目标。

**openPlan 行为规则：**
1. 配置了 `waylinePlanUrl`（去除首尾空白后非空）→ 通过 `openUrlInFh2(waylinePlanUrl)` 跳转到该地址。
2. 未配置 / 为空 / 为纯空白字符串 → 不跳转，弹出 warning 提示：
   > 未配置飞行任务创建页面，无法跳转，请参考上云 API2 前端独立组件说明书添加跳转页面

**示例：loadCockpit 传入您的航线库地址**

```js
window.FH2.loadCockpit('cockpit-container', {
  gateway_sn: 'YOUR_GW_SN',
  drone_sn:   'YOUR_DRONE_SN',
  map: true,
  cockpitConfig: {
    waylinePlanUrl: 'https://custom.example.com/wayline'   // 顶层字段，与 modules 同级
  }
})
```

:::tip
`waylinePlanUrl` 位于配置对象顶层，不要写进 `modules` 内部。运行时同样可通过 `setCockpitConfig({ waylinePlanUrl: '...' })` 动态更新。
:::

## 8. 外接摄像头验密页面地址 - cameraAuthVerifyUrl

`cameraAuthVerifyUrl` 是 **CockpitConfig 顶层可选字段**（与 `waylinePlanUrl`、`layout`、`theme` 同级，非 `modules` 内部），用于指定**您的外接摄像头（EA610 等）验密页面**地址。

**用途：** 当您的直播画面检测到外接摄像头未验证时，主视频区会展示「摄像头未验证」引导页；您点击「去验证」按钮时，驾驶舱会读取该字段决定跳转目标（新标签页打开）。

**跳转行为规则：**
1. 配置了 `cameraAuthVerifyUrl`（去除首尾空白后非空）→ 通过 `window.open` 在新标签页打开该地址。
2. 未配置 / 为空 / 为纯空白字符串 → 跳转到默认的设备维护页：`{当前站点}/paasjs-demo/paas-device-manager.html#/?sn={deviceSn}&type=maintenance`。

> 跳转到目标自定义地址时**不会附加设备 SN 等参数**（与 `waylinePlanUrl` 行为一致，按原样打开）。如您的验密页面需要定位具体设备，请在您的页面内提供设备选择能力。

**示例：loadCockpit 传入验密页面地址**

```js
window.FH2.loadCockpit('cockpit-container', {
  gateway_sn: 'YOUR_GW_SN',
  drone_sn:   'YOUR_DRONE_SN',
  map: true,
  cockpitConfig: {
    cameraAuthVerifyUrl: 'https://custom.example.com/camera-auth'   // 顶层字段，与 modules 同级
  }
})
```

:::tip
`cameraAuthVerifyUrl` 位于配置对象顶层，不要写进 `modules` 内部。运行时同样可通过 `setCockpitConfig({ cameraAuthVerifyUrl: '...' })` 动态更新。
:::

## 9. 完整配置示例

```js
window.FH2.loadCockpit('cockpit-container', {
  gateway_sn: 'YOUR_GW_SN',
  drone_sn:   'YOUR_DRONE_SN',
  map: true,
  cockpitConfig: {
    modules: {
      topBar: {
        features: {
          alertRecord:   false,   // 隐藏告警记录入口
          relayTask:     false,   // 隐藏任务接力入口
          customButtons: [
            {
              id:         'help-center',
              name:       '帮助',
              tips:       '打开您的帮助中心',
              iconUrl:    'https://cdn.example.com/help.png',
              forwardUrl: 'https://help.example.com'
            },
            {
              id:      'notify',
              name:    '通知',
              tips:    '查看系统通知',
              iconUrl: 'https://cdn.example.com/notify.png',
              cb:      function () { myApp.openNotifyPanel() }
            }
          ]
        }
      },
      mainLive: {
        features: {
          flightControls: { visible: false },   // 只读模式：隐藏飞行操控
          footerItems: {
            fts: false, laser: false,           // 单独隐藏 footer 内的 FTS、激光打点
            customButtons: [
              {
                id:      'track',
                name:    '追踪',
                tips:    '启动目标追踪',
                iconUrl: 'https://cdn.example.com/track.png',
                cb:      function () { myApp.startTracking() }
              }
            ]
          }
        }
      },
      subLive: {
        features: { }
      },
      deviceList: {
        // ⚠️ 该模块默认隐藏，以下配置需待模块开放后才有可见效果
        features: { addRemoveDevice: false }   // 禁止加减设备（只读）
      }
    },
    layout: {
      splitRatios: { primary: 75, secondary: 25 }
    }
  }
})
```

## 10. 字段速查表

### 顶层字段

| 字段路径 | 类型 | 说明 | 默认值 | 状态 |
|----------|------|------|--------|------|
| `waylinePlanUrl` | `string` | 您的航线库地址 | `undefined` | ✅ 已生效 |
| `cameraAuthVerifyUrl` | `string` | 您的外接摄像头验密页面地址 | `undefined`（跳转默认设备维护页） | ✅ 已生效 |

### 模块级（modules.\*.visible）

| 字段路径 | 类型 | 说明 | 默认值 |
|----------|------|------|--------|
| `modules.topBar.visible` | `boolean` | 显示/隐藏顶栏 | `true` |
| `modules.mainLive.visible` | `boolean` | 显示/隐藏主视频区 | `true` |
| `modules.subLive.visible` | `boolean` | 显示/隐藏辅视频区 | `true` |
| `modules.map.visible` | `boolean` | 显示/隐藏地图 | `true` |
| `modules.deviceList.visible` | `boolean` | 显示/隐藏设备列表 | ⚠️ 默认隐藏（在后续版本中会持续开放） |

### 顶栏子功能 - TopBar

| 字段路径 | 类型 | 说明 | 默认值 | 状态 |
|----------|------|------|--------|------|
| `modules.topBar.features.deviceList` | `boolean` | 设备列表入口 | `true` | ⚠️ 入口默认隐藏（在后续版本中会持续开放） |
| `modules.topBar.features.alertRecord` | `boolean` | 告警记录 | `true` | ✅ 已生效 |
| `modules.topBar.features.relayTask` | `boolean` | 任务接力 | `true` | ✅ 已生效 |
| `modules.topBar.features.wayline` | `boolean` | 航线规划入口 | `true` | ✅ 已生效 |
| `modules.topBar.features.droneStatus` | `boolean` | 飞机状态遥测条 | `true` | ✅ 已生效 |

## 11. 常见问题

**Q：设置 `visible: false` 后，模块为什么仍然可见？**

请检查是否在 `modules` 下使用了正确的模块 ID（`topBar`、`mainLive`、`subLive`、`map`、`deviceList`，区分大小写）。另外，`setCockpitConfig` 的配置是与默认值合并而非替换，每次调用需带上所有要保持关闭的字段。

**Q：为什么配置了 `modules.deviceList.visible: true`，设备列表还是不显示？**

`deviceList`（设备列表）模块**默认隐藏**（顶栏的设备列表入口按钮同样隐藏），相关功能在后续版本中会持续开放，当前配置为 `true` 也不会显示。模块开放后，本文档中 deviceList 相关配置无需修改您的调用代码即可生效。

**Q：`topBar.features` 用布尔，`mainLive.features` 用 `{ visible }` 对象，为什么不统一？**

历史设计差异。TopBar 的子功能是单按钮的入口开关（布尔语义更清晰），MainLive 的子功能是区域面板（FeatureToggle 为后续扩展更多属性预留了空间）。

**Q：如何单独隐藏 footer(leftToolbar 区) 内的某一个功能（如 FTS、激光打点）？**

用 `modules.mainLive.features.footerItems.<key> = false`。例如隐藏 FTS 与激光打点：`footerItems: { fts: false, laser: false }`。未列出的 key 默认保持全开。注意 `footerItems` 只做配置层门控，不改变设备能力判断——某项最终可见 = 组开关(`gimbalTools`/`lightMode`) && 该 item 开关 && 设备支持该能力。key 列表见「字段速查表 - MainLive footerItems 逐项开关」。

**Q：自定义按钮的 `cb` 回调能否通过 `setCockpitConfig`（JSON）传入？**

不能。`cb` 是函数引用，JSON 序列化时会被丢弃。需要回调的按钮只能在 `loadCockpit` 时通过 JavaScript 代码传入 `cockpitConfig`。仅需跳转的按钮可使用 `forwardUrl` 在 JSON 中配置。

**Q：未配置 `waylinePlanUrl` 时，点击顶栏航线入口会怎样？**

不会跳转，会弹出 warning 提示「未配置飞行任务创建页面，无法跳转，请参考上云 API2 前端独立组件说明书添加跳转页面」。配置了 `waylinePlanUrl`（顶层字段）后，点击即跳转到该地址。

**Q：未配置 `cameraAuthVerifyUrl` 时，点击直播「摄像头未验证」引导页的「去验证」按钮会怎样？**

会跳转到默认的设备维护页（`paas-device-manager.html`，自动带上当前设备 SN）。配置了 `cameraAuthVerifyUrl`（顶层字段）后，点击即在新标签页打开该地址（不附加 SN 参数）。

**Q：`layout`、`shortcutKey`、`settings` 等标注"后续版本开放"的字段会报错吗？**

不会。这些字段写入后会被 merge 进配置，但 UI 层尚未开放对应功能，当前版本中这些字段配置无效（不报错、不生效）。后续版本开放后无需修改您的调用代码，零改动生效。
