# 驾驶舱与设备小窗

驾驶舱提供实时视频直播、飞行状态监控与远程飞行控制功能；设备小窗以浮层形式在地图上并行监看多台设备。两者均依赖 `paas.js`，共享 `window.FH2` 全局单例。

接入前请先完成 [集成前端组件](./00.index.md) 中的前置准备。

## 1. 引入 paas.js

驾驶舱与设备小窗均依赖 `paas.js`，需要在页面中引入。

```html
<script src="http://[服务器地址]/paas.js" fh2></script>
```

加载完成后，全局对象挂载在 `window.FH2`。

## 2. 初始化配置

初始化 SDK 时需要填写以下 3 项配置：

```javascript
function deriveConfig(cfg) {
  var frontHost  = (cfg.frontHost  || '').replace(/\/+$/, '')   // 前端服务地址
  var serverHost = (cfg.serverHost || '').replace(/\/+$/, '')   // 后端 API 地址
  var wssHost    = (cfg.wssHost    || '').replace(/\/+$/, '')   // WebSocket 地址
  return {
    frontHost:  frontHost,
    serverUrl:  serverHost,
    wssUrl:     wssHost,
    paasJsSrc:  frontHost + '/paas.js',
  }
}
```

### 2.1 前端服务地址（frontHost）

输入前端部署资源的地址，该地址需能访问到 `paas.js` 文件。例如在浏览器中访问 `http://[服务器地址]/paas.js` 能成功加载，则填写 `http://[服务器地址]`。如果前端指定了端口，如 `https://[服务器地址]:10443`，则需完整填写含端口的地址。注意当前 HTML 页面的访问协议需与此地址协议一致，避免跨域。

### 2.2 后端接口地址（serverHost）

提供的后端服务接口地址，一般为服务器地址加 `30812` 端口。例如：`http://[服务器地址]:30812`

### 2.3 WebSocket 地址（wssHost）

提供 WebSocket 服务的地址，仅替换为你的服务器域名/IP 即可，路径部分保持不变。例如：`ws://[服务器地址]:30812/openapi/v0.9/notification/ws/v1/notifications`

> 1. 如果页面使用 HTTPS，所有服务地址必须使用 `https://` 和 `wss://`，以避免浏览器跨域（Mixed Content）问题。
> 2. `frontHost` 必须能够访问到 `paas.js` 文件。
> 3. SDK 初始化必须在页面组件加载前执行。

## 3. 鉴权配置（非必须）

如果您的项目需要开启鉴权，可参考如下方式配置：

```javascript
// 先把 token 写入 localStorage，让 headers 闭包能取到
localStorage.setItem('x-user-token', 'your-jwt-token')

var auth = {
  authKeys: ['X-User-Token', 'user_id'],        // 两个鉴权 header 名称
  headers: function () {
    return {
      'X-User-Token': localStorage.getItem('x-user-token') || '',
      'user_id': '<your-user-id>',                 // 替换为您的实际用户标识
    }
  },
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `authKeys` | string[] | 鉴权 header 名称列表，用于网关识别 `auth_keys` 头 |
| `headers` | `() => Record<string, string>` | **必须为函数形式**，每次请求实时取值，适配 token 刷新 |

> **重要**：`headers` 必须写成函数形式（闭包），否则 token 过期后无法自动更新。

### 4.2 完整初始化流程

**调用顺序严格：`initConfig` → `initNotifyCenter` → `loadMap` → `loadCockpit`**

```javascript
window.addEventListener('load', function () {
  var cfg = JSON.parse(localStorage.getItem('fh2_config') || 'null')
  if (!cfg) { location.href = 'index.html'; return }

  var frontHost  = (cfg.frontHost  || '').replace(/\/+$/, '')
  var serverHost = (cfg.serverHost || '').replace(/\/+$/, '')
  var wssHost    = (cfg.wssHost    || '').replace(/\/+$/, '')

  // Token 写入 localStorage，供 auth.headers 闭包读取
  var token = cfg.projectToken || ''
  if (token) localStorage.setItem('x-user-token', token)

  var auth = {
    authKeys: ['X-User-Token', 'user_id'],
    headers: function () {
      return {
        'X-User-Token': localStorage.getItem('x-user-token') || '',
        'user_id': '<your-user-id>',
      }
    },
  }

  // 步骤 1：初始化基础配置
  window.FH2.initConfig({
    serverUrl: serverHost,
    wssUrl:    wssHost,
    hostUrl:   frontHost,
  })

  // 步骤 2：初始化推送中心（auth 被 FH2 内部缓存，后续自动透传）
  window.FH2.initNotifyCenter(wssHost, auth)

  // 步骤 3：加载地图（第 3 个参数为地图推送 ws，不传则地图不订阅设备位置更新）
  window.FH2.loadMap(serverHost, auth, wssHost)

  // 步骤 4：加载驾驶舱
  var gatewaySn = localStorage.getItem('fh2_cockpit_gateway_sn') || ''
  var droneSn   = localStorage.getItem('fh2_cockpit_drone_sn')   || ''

  window.FH2.loadCockpit('cockpit-app-container', {
    gateway_sn:   gatewaySn,
    drone_sn:     droneSn,
    map:          true,
    // theme: 'tech-blue',              // 可选：主题定制
  })
})
```

### 4.3 loadCockpit 参数说明

```typescript
loadCockpit(
  domId: string,
  params: ICockpitParams
): { getVideoType(): any; captureVideoFrame(params?: any): any }
```

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `domId` | string | ✓ | 驾驶舱挂载容器 ID（不带 `#`） |
| `params.gateway_sn` | string | ✓ | 机场/基站序列号 |
| `params.drone_sn` | string | ✓ | 无人机序列号 |
| `params.map` | boolean | ✗ | 是否显示地图，默认 `true` |
| `params.theme` | string \| object | ✗ | 主题：内置预设名（`'default'`/`'tech-blue'`）或扁平 token 对象 |

**返回对象方法：**

| 方法 | 说明 |
|------|------|
| `getVideoType()` | 获取当前视频类型 |
| `captureVideoFrame(params?)` | 捕获视频帧 |

### 4.4 卸载驾驶舱

```typescript
FH2.destroyCockpit(self?: boolean): Promise<boolean>
```

| `self` 值 | 行为 |
|-----------|------|
| `true` | 仅卸载驾驶舱应用，保留地图和 project-app |
| `false`（默认） | 同时卸载驾驶舱、地图和 project-app |

```javascript
// 完整卸载
window.FH2.destroyCockpit()
  .then(function () { console.log('驾驶舱已卸载') })

// 仅卸载驾驶舱，保留地图
window.FH2.destroyCockpit(true)
```

## 5. 设备小窗组件

设备小窗以 SDK 方式拉起无人机/机场/基站设备的直播小窗浮层，调用方自行维护设备列表 UI，SDK 负责展示地图底图 + 设备位置标记 + 设备直播小窗浮层（视频流、飞行状态、任务栏、天气等）。

> **依赖说明**：设备小窗依赖 `paas.js` + `FH2.initConfig` + `FH2.initNotifyCenter` + `FH2.loadMap`，与驾驶舱共享 `window.FH2` / `mapAppState` 全局单例，**驾驶舱与设备小窗不能在同一个 HTML 页面（同一浏览器 Tab）中同时使用，需分别放在独立页面中**。

### 5.1 DOM 骨架与必备样式

```html
<div class="fh2-container">
  <div id="map-app-global"></div>
  <div id="project-app-container" style="display:none"></div>
  <div id="real-time-app-container"></div>
</div>
```

```css
.fh2-container {
  position: relative;
  width: 100vw;
  height: 100vh;
  padding-top: 52px;    /* 与导航栏高度保持一致 */
}

#map-app-global {
  position: absolute;
  top: 52px; left: 0; right: 0; bottom: 0;
  z-index: 1;
}

/* project-app 是数据中转层（复用驾驶舱路由），必须存在但必须隐藏 */
#project-app-container { display: none; }

#real-time-app-container {
  position: absolute;
  top: 52px; left: 0; right: 0; bottom: 0;
  z-index: 10;
  pointer-events: none;   /* 让地图操作能穿透空白区域 */
}

/* qiankun 微应用容器高度修复 —— 必须加 */
#__qiankun_microapp_wrapper_for_real_time_app__,
#__qiankun_microapp_wrapper_for_real_time_app__ > div {
  height: 100% !important;
  pointer-events: none;
}
/* 小窗本身恢复响应点击 */
#__qiankun_microapp_wrapper_for_real_time_app__ .real-time-wrapper {
  pointer-events: auto;
}
```

### 5.2 完整初始化流程

```javascript
window.addEventListener('load', function () {
  var cfg = JSON.parse(localStorage.getItem('fh2_config') || 'null')
  if (!cfg) { location.href = 'index.html'; return }

  var frontHost  = (cfg.frontHost  || '').replace(/\/+$/, '')
  var serverHost = (cfg.serverHost || '').replace(/\/+$/, '')
  var wssHost    = (cfg.wssHost    || '').replace(/\/+$/, '')

  var auth = {
    authKeys: ['X-User-Token', 'user_id'],
    headers: function () {
      return {
        'X-User-Token': localStorage.getItem('x-user-token') || '',
        'user_id': '<your-user-id>',
      }
    },
  }

  // 步骤 1：初始化基础配置
  window.FH2.initConfig({
    serverUrl: serverHost,
    wssUrl:    wssHost,
    hostUrl:   frontHost,
    prjId:         cfg.prjId        || '',   // 项目 ID（若有）
    projectToken:  cfg.projectToken || '',   // 项目 Token（若有）
  })

  // 步骤 2：初始化推送中心
  window.FH2.initNotifyCenter(wssHost, auth)

  // 步骤 3：加载地图（第 3 个参数为地图推送 ws，不传则地图不订阅设备位置更新）
  window.FH2.loadMap(serverHost, auth, wssHost)

  // 步骤 4：拉起设备小窗（devices 为逗号分隔的 SN 字符串）
  window.FH2.loadDeviceWindow('real-time-app-container', {
    devices: 'DOCK-SN-001,DOCK-SN-002',
    map: true,
  }).then(function (windows) {
    // windows 是 DeviceWindowInstance 数组，需保存引用供后续操作使用
    _deviceWindows = windows

    // 给每个小窗设置信息
    windows.forEach(function (w) {
      w.setTask({ status: '执行中', label: '12:30' })
      w.setHmsUrl('https://your-hms.example.com')
      w.setCockpitUrl('https://your-cockpit.example.com')
      w.setOnlineWeather({
        windSpeed: 3.5, precip: 0, temp: 22,
        humidity: 60, icon: 100, wns: 180,
        ionosphereLevel: '0',
      })
    })
  }).catch(function (err) {
    console.error('[设备小窗] loadDeviceWindow 失败', err)
  })
})
```

### 5.3 API 说明

**`FH2.loadDeviceWindow(domId, params?)`**

```typescript
FH2.loadDeviceWindow(domId: string, params?: {
  devices?: string              // 逗号分隔 SN 字符串，默认为空
  map?: boolean                 // 是否加载地图，默认 true
  cameraAuthVerifyUrl?: string  // 基站外接摄像头验密页面地址
}): Promise<DeviceWindowInstance[]>
```

> `loadDeviceWindow` 异步返回，`await` 后保证 micro-app 已挂载、设备拓扑已就绪，后续实例方法同步生效。

### 5.4 小窗实例方法

| 方法 | 说明 |
|------|------|
| `setTask({ status, label? })` | 设置任务栏状态/标签。任务名称由 SDK 自动取机场名称填充，无需传入；不调用则显示 `无任务` |
| `setHmsUrl(url?)` | HMS 健康告警入口跳转链接；传空字符串或不调用则隐藏该入口 |
| `setCockpitUrl(url?)` | 驾驶舱入口跳转链接；传空字符串或不调用则隐藏该入口 |
| `setOnlineWeather(data)` | 推送在线天气快照，立即生效；不调用时天气字段显示 `--` |

**WeatherOnlineData 字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| `windSpeed` | number | 风速（m/s）：≥10 黄色警告，超阈值红色阻飞 |
| `precip` | number | 降水量（mm/h）：0=无雨, (0,2)=小雨, [2,4)=中雨, ≥4=大雨 |
| `temp` | number | 温度（°C）：≤-20 黄色；≤-20 且湿度≥90% 联合黄色 |
| `humidity` | number | 相对湿度 0-100 |
| `icon` | number | 天气状态码（沿用心知天气 icon 编码，如 100=晴，300=阵雨，500=薄雾） |
| `wns` | number | 风向角度 0-360（0=北, 90=东, 180=南, 270=西） |
| `ionosphereLevel` | string（可选） | 电离层活跃度：`-1`=无数据 `0`=平静 `1`=中等 `2`=强 `3`=剧烈 |

### 5.5 动态更新设备列表

```typescript
FH2.updateDeviceWindow(params: { devices: string }): DeviceWindowInstance[]
```

> ⚠️ **注意**：`updateDeviceWindow` 会**返回新的 windows 数组**，必须用返回值替换旧数组，否则对旧实例的操作将失效。

```javascript
// ✅ 正确：保存返回值
_deviceWindows = window.FH2.updateDeviceWindow({ devices: 'NEW-SN-001' }) || []

// ❌ 错误：忽略返回值，旧 windows 数组仍指向已移除的实例
window.FH2.updateDeviceWindow({ devices: 'NEW-SN-001' })
```

> **优先用 `updateDeviceWindow`，不要先 `destroyDeviceWindow` 再重新 `loadDeviceWindow`**，避免不必要的卸载重挂载开销和潜在的 unmount 报错。

### 5.6 销毁小窗

```typescript
FH2.destroyDeviceWindow(self?: boolean): Promise<void>
```

| `self` 值 | 行为 |
|-----------|------|
| `true` | 仅销毁小窗浮层，保留地图和 project-app |
| `false`（默认） | 同时销毁地图、project-app 和小窗浮层 |

```javascript
window.FH2.destroyDeviceWindow()
```

## 6. 已知限制

| 组件 | 限制说明 |
|------|---------|
| **驾驶舱** | `deviceList` 模块默认隐藏，在后续版本中会持续开放 |
| **驾驶舱** | `topBar` 的 `layout`、`shortcutKey`、`settings` 后续版本开放，当前配置无效但不报错 |
| **设备小窗** | 当前 WebSocket 通知使用 `initMock()` 空实现，DRC/摇杆/PSDK 等实时通知暂不可用 |
| **设备小窗** | 没有暴露 `on('error', ...)` 事件，运行时问题只能通过 Console 和 Network 面板排查 |
| **两者共用** | 共享 `window.FH2` 全局单例，驾驶舱与设备小窗不能在同一 HTML 页面（同一浏览器 Tab）中同时使用 |
