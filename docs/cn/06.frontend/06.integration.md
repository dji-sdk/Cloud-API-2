# 集成参考

本篇汇总各前端组件的主题定制字段、完整接入页面示例、常见问题与 API 速查表，供接入过程中随时查阅。各组件的接入步骤见对应组件文档。

## 1. 主题定制

各组件均支持自定义主题色，可在初始化时传入，也可在运行时热切换。

### 1.1 航线编辑组件

**初始化时指定**

```javascript
new WaylineEditor({
  // ...其他配置
  theme: {
    primaryColor:      '#0f3460',
    primaryHoverColor: '#1a4f8a',
    primaryFocusColor: '#0a264a',
    bgBasic:           '#1a1a2e',
    bgSub:             '#16213e',
    bgModal:           '#0a0a1a',
    bgHighlight:       '#0a0a1a',
    controlBg:         '#16213e',
    controlHoverBg:    '#1a2745',
    borderColor:       '#333',
    listActiveBg:      'rgba(15,52,96,0.4)',
    listHoverBg:       'rgba(26,79,138,0.3)',
  },
})
```

**运行时热切换**（`mount()` 后随时调用）

```javascript
editor.setTheme({ primaryColor: '#00b96b', bgBasic: '#1a1a1a' })
```

**ITheme 字段说明**

| 字段 | 说明 |
|------|------|
| `primaryColor` | 主色（按钮、链接、激活态） |
| `primaryHoverColor` | 主色 hover 态 |
| `primaryFocusColor` | 主色 focus 态 |
| `bgBasic` | 基础背景色 |
| `bgSub` | 次级背景色（侧栏、卡片） |
| `bgModal` | 弹窗背景色 |
| `bgHighlight` | 输入框/高亮区域背景色 |
| `controlBg` | 控件背景色 |
| `controlHoverBg` | 控件 hover 背景色 |
| `borderColor` | 边框色 |
| `listActiveBg` | 列表项激活态背景色 |
| `listHoverBg` | 列表项 hover 态背景色 |

### 1.3 驾驶舱组件

驾驶舱主题基于约 90 个 **snake_case 语义化 token**，支持三种定制方式：

1. 初始化时传入 `theme` 参数
2. 运行时调用 `FH2.setCockpitTheme()` 等 API
3. 驾驶舱内置可视化主题面板（调色 + 导出 JSON）

**两种传入形态**

| 形态 | 类型 | 说明 |
|------|------|------|
| 预设名 | string | `'default'`（默认深色）、`'tech-blue'`（科技蓝） |
| 扁平 token 对象 | `Record<string, string>` | **支持部分覆盖**，只传需要修改的 key |

**初始化时指定**

```javascript
// 方式一：内置预设
window.FH2.loadCockpit('cockpit-app-container', {
  gateway_sn: 'GW12345678',
  drone_sn: 'DV12345678',
  map: true,
  theme: 'tech-blue',
})

// 方式二：部分覆盖 token（只改品牌色，其余保持默认）
window.FH2.loadCockpit('cockpit-app-container', {
  gateway_sn: 'GW12345678',
  drone_sn: 'DV12345678',
  map: true,
  theme: {
    function_brand_primary_enabled: '#06b6d4',
    function_brand_primary_hover:   '#22d3ee',
    function_brand_primary_pressed: '#0891b2',
  },
})
```

**运行时主题 API**

| 方法 | 说明 |
|------|------|
| `FH2.setCockpitTheme(tokens)` | 覆盖主题 token（部分覆盖，即时生效） |
| `FH2.setCockpitPreset(preset)` | 切换内置预设：`'default'` / `'tech-blue'` |
| `FH2.resetCockpitTheme()` | 重置为默认预设 |

```javascript
// 换成 ISV 品牌绿
window.FH2.setCockpitTheme({
  function_brand_primary_enabled: '#34d399',
  function_brand_primary_hover:   '#5eead4',
  function_brand_primary_pressed: '#10b981',
})
```

**Token 分组说明（按前缀）**

| 分组前缀 | 控制范围 | 示例 |
|----------|----------|------|
| `bg_*` | 各层级背景色 | `bg_primary_default` |
| `border_*` | 各层级边框色 | `border_primary_default` |
| `component_*` | 控件各状态填充色 | `component_primary_enabled` |
| `function_*` | 功能色：品牌色/危险/成功/警告 | `function_brand_primary_enabled` |
| `icon_*` | 图标色 | `icon_primary_default` |
| `text_*` | 文本色 | `text_primary_default` |

**常用定制场景**

| 场景 | 覆盖的 token |
|------|-------------|
| 换品牌主色 | `function_brand_primary_enabled/hover/pressed/selected` |
| 整体换背景 | `bg_primary_default`、`bg_secondary_default`、`bg_tertiary_default` |
| 调整文本对比度 | `text_primary_default`、`text_secondary_default` |

**可视化调试（推荐）**

1. 在驾驶舱顶栏点击 `主题切换` 打开配置面板。
2. 逐个 token 调色，实时预览。
3. 点击 `导出 JSON`，得到扁平 token 键值对。
4. 将导出的 JSON 直接作为 `theme` 或 `setCockpitTheme` 的入参使用。

### 1.4 设备管理组件

内置 `'light'`（默认）和 `'dark'` 两套主题，同时支持自定义 ThemeTokens 对象。

**内置主题**

```javascript
await window.UranusDeviceManagerApp.setupDeviceManager({
  // ...其它字段
  theme: 'dark',   // 'light' 或 'dark'
  antThemeBaseUrl: 'http://[服务器地址]/paasjs-demo/device-manager-sdk-v2/ant-theme',
})
```

**自定义主题（推荐流程）**

1. 在已挂载页面调用 `window.UranusDeviceManagerApp.showThemePanel()` 打开配置面板。
2. 调整各 token 颜色，直到满意。
3. 点击 `导出 JSON`，得到完整 ThemeTokens 对象。
4. 将导出的 JSON 作为 `theme` 传入 `setupDeviceManager`。

```javascript
var CUSTOM_THEME = {
  // 将导出的 JSON 粘贴至此
  bg_primary_default:   '#ffffff',
  bg_secondary_default: '#fafafa',
  // ...其余 token
}

await window.UranusDeviceManagerApp.setupDeviceManager({
  // ...其它字段
  theme: (CUSTOM_THEME && typeof CUSTOM_THEME === 'object') ? CUSTOM_THEME : 'light',
  antThemeBaseUrl: 'http://[服务器地址]/paasjs-demo/device-manager-sdk-v2/ant-theme',
})
```

> **注意**：切换主题需重新调用 `setupDeviceManager({ theme })`，因为它是幂等的，后续调用只刷新主题与回调，不会重复初始化 HTTP/WebSocket。

## 3. 常见问题

**Q1：地图不显示怎么办？**

按以下顺序排查：

1. DOM 容器有正确的 ID 和尺寸（参考各组件的 DOM 骨架要求）。
2. `wssUrl` 配置正确，且服务可访问。
3. 对于 `WaylineEditor` / `FlyDataReplay`：确认 `window.Cesium` 已存在（Cesium 必须在 SDK 之前同步加载）。
4. 是否忘记调用 `loadMap()`（调用顺序：`new SDK()` → `on('error')` → `await loadMap()` → `mount()`）。

**Q2：报错 6002（MAP_INIT_ERROR）是什么原因？**

99% 是**忘记调用 `loadMap()` 或调用顺序错误**。

```javascript
// ❌ 错误：mount 在 loadMap 之前
var player = new window.FlyDataReplay(opts)
player.mount(container)

// ✅ 正确：必须先 loadMap
var player = new window.FlyDataReplay(opts)
await player.loadMap()
player.mount(container)
```

**Q3：鉴权报 401 / WebSocket 报 4001 怎么处理？**

排查顺序：

1. `authKeys` 与 `headers` 对象的 key 是否**完全一致**（区分大小写）。
2. Token 是否过期 → `headers` 改为函数形式，每次取最新值。
3. 如果用了 Webhook 鉴权，确认 Webhook 服务是否在 3 秒内响应。

```javascript
// ❌ 错误：静态对象，token 过期后无法自动更新
var auth = { authKeys: ['X-User-Token'], headers: { 'X-User-Token': 'xxx' } }

// ✅ 正确：函数形式，每次请求取最新值
var auth = {
  authKeys: ['X-User-Token', 'user_id'],
  headers: function () {
    return {
      'X-User-Token': localStorage.getItem('x-user-token') || '',
      'user_id': '<your-user-id>',
    }
  },
}
```

**Q4：驾驶舱的 deviceList 模块为什么不显示？**

`deviceList`（设备列表）模块**默认隐藏**，即使配置 `modules.deviceList.visible: true` 也不会显示。在后续版本中会持续开放，届时调用代码无需修改即可生效。

**Q5：同一页面能同时加载驾驶舱和飞行记录吗？**

**不能同时挂载**，两者共享全局单例。飞行记录已不依赖 `paas.js`，但仍依赖 Cesium 全局实例，同一页面同一时刻只能有一个活跃实例。

**例外**：`DJILivePlayer`（直播大屏）完全独立，可以与任何组件共存于同一页面，且支持同时多实例。

**Q6：切换飞行任务（FlyDataReplay）怎么做？**

必须先销毁旧实例再创建新实例：

```javascript
if (player) {
  player.destroy()
  player = null
}
player = new window.FlyDataReplay({ taskId: newTaskId, /* ...其他配置 */ })
await player.loadMap()
player.mount(document.getElementById('fly-data-app-container'))
```

**Q7：HTTPS 页面出现 Mixed Content 报错？**

如果页面使用 HTTPS，所有服务地址必须统一为 `https://` 和 `wss://`：

- `serverUrl` → `https://`
- `wssUrl` → `wss://`
- `hostUrl` → `https://`
- Cesium 和 SDK 资源路径 → `https://`

**Q8：设备小窗的 updateDeviceWindow 调用后部分小窗没生效？**

`updateDeviceWindow` **有返回值**，必须保存返回的新 windows 数组：

```javascript
// ✅ 正确：保存返回值
_deviceWindows = window.FH2.updateDeviceWindow({ devices: 'SN-001,SN-002' }) || []

// ❌ 错误：忽略返回值，旧数组仍指向已移除的实例
window.FH2.updateDeviceWindow({ devices: 'SN-001,SN-002' })
```

**Q9：航线编辑器取消创建/编辑时为什么报错？**

`editor.create()` 在取消操作时会以 `Error('User cancelled')` reject，这是**正常行为**，不是 bug。必须挂 `.catch()` 处理：

```javascript
editor.create()
  .then(function (res) { /* 创建成功 */ })
  .catch(function (err) {
    if (err.message === 'User cancelled') {
      console.log('已取消，正常流程')
    } else {
      console.error('创建失败:', err.message)
    }
  })
```

## 4. API 速查表

### 4.1 FH2 全局 API（`window.FH2`）

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `initConfig(config)` | 初始化 SDK 基础配置（serverUrl/wssUrl/hostUrl） | void |
| `initNotifyCenter(wssUrl, auth)` | 初始化推送中心 WebSocket | void |
| `loadMap(serverUrl, auth, wssUrl?)` | 加载地图（第 3 个参数为地图推送 ws） | void |
| `loadCockpit(domId, params)` | 加载驾驶舱（支持 `cockpitConfig` / `theme`） | Object |
| `setCockpitConfig(config)` | 运行时更新驾驶舱模块显隐配置 | void |
| `getCockpitConfig()` | 读取最近一次写入的驾驶舱配置 | Object |
| `setCockpitTheme(tokens)` | 运行时覆盖驾驶舱主题 token | void |
| `setCockpitPreset(preset)` | 切换驾驶舱内置主题预设 | void |
| `resetCockpitTheme()` | 重置驾驶舱主题至默认 | void |
| `destroyCockpit(self?)` | 卸载驾驶舱（`self=true` 保留地图） | Promise |
| `loadDeviceWindow(domId, params?)` | 加载设备小窗 | `Promise<实例数组>` |
| `updateDeviceWindow(params)` | 更新设备小窗设备列表（有返回值） | `DeviceWindowInstance[]` |
| `destroyDeviceWindow(self?)` | 卸载设备小窗 | Promise |

### 4.7 错误码汇总

**数字错误码**（`WaylineEditor` / `FlyDataReplay` / `WaylineView` 共用）

| 错误码 | 说明 |
|--------|------|
| `4001` | WebSocket 鉴权失败 |
| `4002` | WebSocket 连接断开 |
| `5000` | API 请求失败（网络错误或服务端 5xx） |
| `5001` | API 鉴权失败（401/403） |
| `6000` | 航线数据解析失败（KMZ 格式异常） |
| `6001` | WASM 模块加载失败 |
| `6002` | 地图初始化失败（最常见：忘记 `loadMap`） |
| `6003` | 运行时依赖加载失败（`WaylineView` 专用） |
| `7000` | OSS 上传失败（`WaylineEditor` 专用） |

**字符串错误码**（`DJILivePlayer` 独立体系）

| 错误码 | 说明 |
|--------|------|
| `NOT_INITIALIZED` | 未调用 `initLivePlayer()` |
| `DEVICE_OFFLINE` | 设备离线 |
| `TOKEN_EXPIRED` | Token 过期 |
| `AUTH_FAILED` | 认证失败 |
| `DUPLICATE_INSTANCE` | 同 SN/Camera/Video 重复实例 |
| `CAMERA_NEED_AUTH` | 摄像头需要验密 |
| `START_LIVE_FAILED` | 开播失败 |

### 4.8 各组件依赖关系速查

| 组件 | 依赖 paas.js | 多实例 | 备注 |
|------|-------------|-------|------|
| 驾驶舱（Cockpit） | ✅ 依赖 | ❌ 单例 | 依赖 `initConfig` + `initNotifyCenter` + `loadMap` |

| 直播大屏（`DJILivePlayer`） | ❌ 独立 | ✅ 多实例 | 可与任何组件共存于同一页面 |
