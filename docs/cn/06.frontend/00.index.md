# 集成前端组件

上云 API 2 提供开箱即用的前端组件，助您在自己的 Web 应用中快速构建无人机管理和远程作业能力。所有组件均以浏览器原生 JS 形态提供，通过 `paas.js` 或各组件自带的 SDK 资源引入，不限定前端框架。

## 组件矩阵

| 组件 | 全局对象 | 用途 | 文档 |
|---|---|---|---|
| 驾驶舱 | `FH2.loadCockpit` | 实时视频直播、飞行状态监控与飞行控制 | [驾驶舱与设备小窗](./01.cockpit.md)、[模块化配置](./07.cockpit-config.md) |
| 设备小窗 | `FH2.loadDeviceWindow` | 在页面中并行监看多台设备的画面与状态 | [驾驶舱与设备小窗](./01.cockpit.md) |
| 航线编辑 | `WaylineEditor` | 可视化创建与编辑航线任务，支持拼接与拓扑连线 | [航线组件](./02.wayline.md) |
| 航线预览 | `WaylineView` | 只读预览一组航线 | [航线组件](./02.wayline.md) |
| 飞行记录 | `FlyDataReplay` | 历史飞行数据查看与回放 | [飞行记录](./03.flight-records.md) |
| 直播大屏 | `DJILivePlayer` | 多路视频网格化播放 | [直播大屏](./04.livestream.md) |
| 设备管理 | `UranusDeviceManagerApp` | 设备列表、运维、告警、维保、固件管理 | [设备管理组件](./05.device-manager.md) |

主题定制、完整接入示例、常见问题与 API 速查表见 [集成参考](./06.integration.md)。

## 前置准备

- 已部署好上云 API 2 私有化安装包，部署方式请参考 [部署上云 API 2 应用运行与设备管控底座](../02.deployment/00.index.md)。

- 前端组件接入 Demo 已经集成到上云 API 2 底座中，底座部署完成后可直接访问：

  ```
  http://[服务器地址]/paasjs-demo/index.html
  ```

  各组件的初始化代码均已放在对应 HTML 文件中，可直接参考。

各组件的引入方式不同：驾驶舱与设备小窗依赖 `paas.js`，其余组件各自引入独立的 SDK 资源，均见对应文档。
