# 设备管理组件

设备管理组件（`UranusDeviceManagerApp`）以模块化方式提供设备列表、设备运维、告警信息、设备定损、维保看板、行业无忧与固件管理能力，每个模块可独立挂载到宿主页面的任意容器。组件自带 SDK 资源，不依赖 `paas.js`。

接入前请先完成 [集成前端组件](./00.index.md) 中的前置准备。

## 1. 引入 SDK 资源

```html
<!-- 1. 组件库样式 -->
<link rel="stylesheet" href="http://[服务器地址]/paasjs-demo/device-manager-sdk-v2/index.css">

<!-- 2. 组件库主包（所有 mountXxx 函数均在 window.UranusDeviceManagerApp 里） -->
<script src="http://[服务器地址]/paasjs-demo/device-manager-sdk-v2/index.js"></script>
```

加载完成后，挂载在 `window.UranusDeviceManagerApp`，从中解构所需函数：

```javascript
var UDM = window.UranusDeviceManagerApp
var setupDeviceManager       = UDM.setupDeviceManager
var mountDeviceList          = UDM.mountDeviceList
var mountMaintenanceDrawer   = UDM.mountMaintenanceDrawer
var mountDeviceHmsDrawer     = UDM.mountDeviceHmsDrawer
var mountAirportReportDrawer = UDM.mountAirportReportDrawer
// ... 按需取用
```

## 2. 初始化配置

在调用任何 `mountXxx()` 之前，必须先完成全局初始化。`setupDeviceManager` 为**幂等设计**，可安全多次调用——首次完整初始化，后续调用仅更新 `callbacks` 和 `slots`。

```javascript
window.addEventListener('load', function () {
  window.UranusDeviceManagerApp.setupDeviceManager({
    serverUrl: 'http://[服务器地址]:30812',   // 库内部自动添加 /gateway 前缀
    wsUrl:     'ws://[服务器地址]:30812/openapi/v0.9/notification/ws/v1/notifications',
    auth: {
      authKeys: ['X-User-Token', 'user_id'],
      headers: function () {
        return {
          'X-User-Token': localStorage.getItem('x-user-token') || '',
          'user_id': '<your-user-id>',
        }
      },
    },
    locale:          'zh',     // 'zh' 或 'en'，默认 'zh'
    theme:           'light',  // 'light' 或 'dark'，或自定义 token 对象
    antThemeBaseUrl: 'http://[服务器地址]/paasjs-demo/device-manager-sdk-v2/ant-theme',
    callbacks: {
      onError: function (err) { console.error('[DeviceManager]', err) },
    },
  }).then(function () {
    console.log('设备管理初始化成功')
  }).catch(function (err) {
    console.error('设备管理初始化失败', err)
  })
})
```

**SetupParams 参数说明**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `serverUrl` | string | ✓ | API 网关地址（库内部自动添加 `/gateway` 前缀） |
| `wsUrl` | string | ✓ | WebSocket 推送地址 |
| `auth` | AuthConfig | ✓ | 鉴权配置，见下表 |
| `locale` | string | ✗ | 语言，默认 `'zh'`，支持 `'zh'` / `'en'` |
| `theme` | string \| object | ✗ | 主题，默认 `'light'`，支持 `'light'` / `'dark'` 或自定义 token 对象 |
| `antThemeBaseUrl` | string | ✗ | Ant Design 双主题 CSS 产物路径，默认 `'/ant-theme'` |
| `callbacks.onError` | function | ✗ | 全局错误回调 |
| `slots` | SlotRegistry | ✗ | 自留地插槽注册，见 [4. 自留地插槽](#_4-自留地插槽) |

**AuthConfig**

| 字段 | 类型 | 说明 |
|------|------|------|
| `authKeys` | string[] | 需注入到请求 header 的 key 名列表 |
| `headers` | object \| `() => Record<string, string>` | **推荐函数形式**，每次请求时实时取值，适配 token 刷新 |

## 3. 模块化挂载

### 3.1 通用规范

所有 `mountXxx()` 函数接受相同结构的参数，返回相同的操作句柄。

**MountOptions**

```typescript
interface MountOptions {
  container: HTMLElement | string   // 挂载目标：DOM 元素或 CSS 选择器
  props?:    Record<string, any>    // 透传给内部业务组件的 props
  on?:       Record<string, Function>  // 事件监听器
}
```

**MountHandle**（`mountXxx()` 的返回值）

```typescript
interface MountHandle {
  unmount: () => void                    // 卸载实例，清空容器 DOM
  update:  (opts: { props?, on? }) => void  // 热更新 props 或事件监听器，不销毁实例
}
```

**典型生命周期**

```javascript
// 挂载
var handle = mountDeviceList({ container: '#slot', props: { deviceType: 'airport' } })

// 选项卡切换或页面跳转时卸载
handle.unmount()

// 不销毁实例的情况下更新 props（如切换设备 SN）
handle.update({ props: { sn: 'NEW_SN' } })
```

> **内容模式 vs 抽屉模式**
> - **内容模式**（`mountXxx`）：组件直接在容器内渲染，由调用方控制容器大小
> - **抽屉模式**（`mountXxxDrawer`）：组件以右侧滑出抽屉形式展现，关闭时触发 `close` 事件，监听后调用 `handle.unmount()`

### 3.2 各模块速查表

| 模块 | 内容模式 | 抽屉模式 |
|------|---------|---------|
| 设备列表 | `mountDeviceList` | — |
| 设备运维 | `mountMaintenance` | `mountMaintenanceDrawer` |
| 告警信息 | `mountDeviceHms` | `mountDeviceHmsDrawer` |
| 设备定损与反馈 | `mountAirportReport` | `mountAirportReportDrawer` |
| 维保看板 | `mountMaintenanceBoard` | `mountMaintenanceBoardDrawer` |
| 行业无忧 | `mountIndustryWarranty` | `mountIndustryWarrantyDrawer` |
| 固件管理 | `mountFirmwareManagement` | — |

### 3.3 设备列表 `mountDeviceList`

```javascript
var handle = mountDeviceList({
  container: '#slot',
  props: {
    deviceType: 'airport',   // 'airport'（机场）| 'drone'（飞行器），默认 'airport'
  },
})
```

| props 字段 | 类型 | 必填 | 说明 |
|-----------|------|------|------|
| `deviceType` | `'airport' \| 'drone'` | ✗ | 默认显示的设备类型，默认 `'airport'` |

### 3.4 设备运维 `mountMaintenance` / `mountMaintenanceDrawer`

```javascript
var handle = mountMaintenanceDrawer({
  container: '#slot',
  props: {
    sn:                 'AIRPORT_SN',   // 机场 SN，必填
    hideMoreHms:        true,           // 单独挂载时建议设为 true，隐藏「更早告警」跨模块入口
    hideAirportReport:  true,           // 单独挂载时建议设为 true，隐藏「设备定损」跨模块入口
  },
  on: {
    close:                        function () { handle.unmount() },
    'open-airport-report':        function (data) { /* 跳转到设备定损 */ },
    'open-maintain-service':      function (airport) { /* 打开维保服务 */ },
    'open-care':                  function () { /* 跳转到行业无忧 */ },
    'maintenance-airport-update': function (airport) { /* 机场设备信息更新 */ },
    'maintenance-host-update':    function (host) { /* 载机设备信息更新 */ },
  },
})
```

| props 字段 | 类型 | 必填 | 说明 |
|-----------|------|------|------|
| `sn` | string | ✓ | 机场设备 SN |
| `hideMoreHms` | boolean | ✗ | 隐藏 `更早告警` 入口，**单独挂载时建议 `true`** |
| `hideAirportReport` | boolean | ✗ | 隐藏 `设备定损与反馈` 按钮，**单独挂载时建议 `true`** |

| 事件名 | 回调参数 | 说明 |
|--------|---------|------|
| `close` | — | 抽屉关闭（仅抽屉模式触发） |
| `open-airport-report` | `{ device_sn: string }` | 点击 `设备定损与反馈` 入口（`hideAirportReport: false` 时触发） |
| `open-maintain-service` | `airport` | 点击维保服务入口 |
| `open-care` | — | 点击行业无忧入口 |
| `maintenance-airport-update` | `airport` | 机场设备信息发生更新 |
| `maintenance-host-update` | `host` | 载机设备信息发生更新 |

### 3.5 告警信息 `mountDeviceHms` / `mountDeviceHmsDrawer`

```javascript
var handle = mountDeviceHmsDrawer({
  container: '#slot',
  props: {
    airportSn:            'AIRPORT_SN',
    droneSn:              'DRONE_SN',    // 可选
    relaySn:              'RELAY_SN',    // 可选
    currentHmsDeviceType: 'airport',     // 默认展示的设备类型选项卡
    hideAction:           true,          // 单独挂载时建议 true，隐藏「操作」列
  },
  on: {
    close:             function () { handle.unmount() },
    'show-more-hms-page': function (payload) { /* 跳转告警详情 */ },
  },
})
```

| props 字段 | 类型 | 必填 | 说明 |
|-----------|------|------|------|
| `airportSn` | string | ✓ | 机场设备 SN |
| `droneSn` | string | ✗ | 载机设备 SN |
| `relaySn` | string | ✗ | 中继器设备 SN |
| `baseStationSn` | string | ✗ | 基站设备 SN |
| `currentHmsDeviceType` | string | ✗ | 初始显示的设备类型选项卡，默认 `'airport'` |
| `hideAction` | boolean | ✗ | 隐藏 `操作` 列（反馈创建入口），**单独挂载时建议 `true`** |

| 事件名 | 回调参数 | 说明 |
|--------|---------|------|
| `close` | — | 抽屉关闭 |
| `show-more-hms-page` | `{ sn?, record? }` | 跳转至告警详情 |

## 4. 自留地插槽

自留地插槽允许在组件库预留的指定位置挂载自定义 UI，支持 React、Vue 或原生 JavaScript 任意框架实现。

### 4.1 当前开放的插槽

| 插槽名 | 所在模块 | 位置 |
|--------|---------|------|
| `maintenance-remote-debug-extra` | 设备运维 | 远程调试面板 header 右侧，与 `设备日志` 按钮并排 |

**`maintenance-remote-debug-extra` 的 `ctx` 字段**

| 字段 | 说明 |
|------|------|
| `airport` | 当前机场设备信息 |
| `drone` | 关联载机设备信息 |
| `node` | 关联中继器设备信息 |
| `isDroneExist` | 是否存在关联载机 |
| `isRelayExist` | 是否存在关联中继器 |

### 4.2 注册方式

通过 `setupDeviceManager` 的 `slots` 参数注册：

```javascript
setupDeviceManager({
  // ...其他参数
  slots: {
    'maintenance-remote-debug-extra': function (el, ctx) {
      var btn = document.createElement('button')
      btn.textContent = 'ISV 自定义按钮'
      btn.style.cssText = 'padding:4px 12px; border:1px solid #1677ff; border-radius:4px; cursor:pointer; color:#1677ff;'
      btn.onclick = function () {
        console.log('当前机场 SN：', ctx.airport && ctx.airport.device_sn)
      }
      el.appendChild(btn)
      // 返回清理函数（ctx 变化时自动调用）
      return function () { btn.remove() }
    },
  },
})
```

> **说明**：每次 `ctx` 变化时，库会先执行返回的清理函数，再重新调用 handler（传入最新 ctx）。handler 内无需自行监听 ctx 变化。

## 5. 主题定制

内置 `'light'`（默认）和 `'dark'` 两套主题，同时支持自定义 token 对象实现品牌化定制。

### 5.1 使用内置主题

```javascript
setupDeviceManager({
  // ...
  theme: 'dark',   // 'light' 或 'dark'
  antThemeBaseUrl: 'http://[服务器地址]/paasjs-demo/device-manager-sdk-v2/ant-theme',
})
```

### 5.2 自定义主题

推荐通过可视化面板配置，无需手写 token：

1. 在已挂载的页面调用 `window.UranusDeviceManagerApp.showThemePanel()` 打开主题面板。
2. 调整各色值直到满意。
3. 点击 `导出 JSON`，得到完整 token 对象。
4. 将导出结果作为 `theme` 传入 `setupDeviceManager`。

```javascript
var CUSTOM_THEME = {
  // 将导出的 JSON 对象粘贴至此
  // "bg_primary_default": "#ffffff",
  // "bg_secondary_default": "#fafafa",
  // ...
}

setupDeviceManager({
  // ...
  theme: (CUSTOM_THEME && typeof CUSTOM_THEME === 'object') ? CUSTOM_THEME : 'light',
  antThemeBaseUrl: 'http://[服务器地址]/paasjs-demo/device-manager-sdk-v2/ant-theme',
})
```

> 切换主题需重新调用 `setupDeviceManager({ theme })`。因为 `setupDeviceManager` 是幂等的，后续调用只刷新主题与回调，不会重复初始化 HTTP/WebSocket。

## 6. 完整接入示例

以下是典型的多选项卡宿主页面接入模式：

```javascript
var UDM = window.UranusDeviceManagerApp
var currentHandle = null

// 步骤 1：全局初始化（一次）
UDM.setupDeviceManager({
  serverUrl:       'http://[服务器地址]:30812',
  wsUrl:           'ws://[服务器地址]:30812/openapi/v0.9/notification/ws/v1/notifications',
  auth: {
    authKeys: ['X-User-Token', 'user_id'],
    headers: function () {
      return {
        'X-User-Token': localStorage.getItem('x-user-token') || '',
        'user_id': '<your-user-id>',
      }
    },
  },
  locale:          'zh',
  theme:           'light',
  antThemeBaseUrl: 'http://[服务器地址]/paasjs-demo/device-manager-sdk-v2/ant-theme',
  callbacks: {
    onError: function (err) { console.error('[DeviceManager]', err) },
  },
}).then(function () {
  // 步骤 2：默认展示设备列表
  switchTab('list', { deviceType: 'airport' })
})

// 步骤 3：选项卡切换时按需挂载
function switchTab(tabKey, props) {
  // 卸载上一个模块
  if (currentHandle) {
    currentHandle.unmount()
    currentHandle = null
  }

  var slot = document.getElementById('udm-slot')
  slot.innerHTML = ''

  var TAB_MAP = {
    'list':           UDM.mountDeviceList,
    'maintenance':    UDM.mountMaintenanceDrawer,
    'hms':            UDM.mountDeviceHmsDrawer,
    'damage':         UDM.mountAirportReportDrawer,
    'maintain-board': UDM.mountMaintenanceBoardDrawer,
    'industry':       UDM.mountIndustryWarrantyDrawer,
    'firmware':       UDM.mountFirmwareManagement,
  }

  currentHandle = TAB_MAP[tabKey]({
    container: slot,
    props:     props || {},
    on: {
      close: function () {
        currentHandle && currentHandle.unmount()
        currentHandle = null
        slot.innerHTML = ''
      },
      // 运维 → 定损跨选项卡跳转
      'open-airport-report': function (data) {
        switchTab('damage', data && data.device_sn ? { selectedSn: data.device_sn } : {})
      },
      // 告警信息跳转
      'show-more-hms-page': function (payload) {
        var sn = (payload && payload.sn) || (payload && payload.record && payload.record.device_sn)
        switchTab('hms', sn ? { airportSn: sn } : {})
      },
      'open-care': function () { switchTab('industry', {}) },
    },
  })
}
```
