# 地图组件

地图组件（`MapView`）是独立的地图 SDK，提供三维地图底座，并以插件方式叠加**自定义飞行区**、涂鸦标注、模型和设备拓扑等能力。组件自带 SDK 资源，不依赖 `paas.js`。

接入前请先完成 [集成前端组件](./00.index.md) 中的前置准备。

> 地图组件仅提供地图与绘制能力，不含飞行区列表、搜索、启用/停用等管理界面。这部分界面请基于后端接口自行构建，飞行区数据的增删改查与下发见 [安全服务](../09.sdk/features/map/safety-service.md)。

## 1. 引入 SDK 资源

地图组件需要加载 **Cesium** 和 **SDK 自身两个文件**（将 `[服务器地址]` 替换为你的前端服务地址）：

```html
<!-- 1. Cesium 全局（提供 window.Cesium） -->
<link rel="stylesheet" href="http://[服务器地址]/paasjs-demo/sdk-runtime/cesium/Widgets/widgets.css">
<script src="http://[服务器地址]/paasjs-demo/sdk-runtime/cesium/Cesium.js"></script>

<!-- 2. 地图 SDK（defer 保证 Cesium 先加载） -->
<link rel="stylesheet" href="http://[服务器地址]/paasjs-demo/map-sdk/index.css">
<script defer src="http://[服务器地址]/paasjs-demo/map-sdk/index.js"></script>
```

## 2. 容器与样式

地图容器需要有明确的宽高，SDK 会在容器内渲染地图：

```html
<div id="map-container"></div>
```

```css
#map-container { position: fixed; top: 0; bottom: 0; left: 0; right: 0; }
#map-container > div { width: 100%; height: 100%; }
```

## 3. 初始化

```typescript
new MapView(options: IMapViewOptions): MapView
```

**IMapViewOptions 参数**

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `api.baseUrl` | string | ✓ | 后端服务地址，例如 `http://[服务器地址]:30812/gateway` |
| `api.auth` | IAuth | ✓ | HTTP 鉴权配置，格式与其他前端组件一致，见 [配置鉴权](../10.auth.md) |
| `api.ws` | string | ✗ | 推送中心 WebSocket 地址，涂鸦插件据此订阅并实时刷新元素；省略则不订阅 |
| `container` | string \| HTMLElement | ✓ | 地图容器，例如 `'#map-container'` |
| `env.cesiumBaseUrl` | string | ✗ | Cesium 资源目录 URL，建议传入，例如 `/paasjs-demo/sdk-runtime/cesium/` |
| `plugins` | object | ✗ | 插件配置，见下节；整块省略则为纯地图 |

**完整初始化示例**

```javascript
var auth = {
  authKeys: ['user_id'],
  headers: { user_id: '<your-user-id>' },
  // 生产环境请换为函数形式：
  // headers: function () { return { 'X-User-Token': localStorage.getItem('x-user-token') || '' } }
}

window.addEventListener('load', async function () {
  var view = new window.MapView({
    api: {
      baseUrl: 'http://[服务器地址]:30812/gateway',
      auth: auth,
      ws: 'ws://[服务器地址]:30812/openapi/v0.9/notification/ws/v1/notifications',
    },
    container: '#map-container',
    env: {
      cesiumBaseUrl: '/paasjs-demo/sdk-runtime/cesium/',
    },
    plugins: {
      flightArea: true,   // 自定义飞行区
    },
  })

  // 初始镜头：load 之前调用，地图就绪后自动飞到该位置
  view.recenter({ longitude: 114.0579, latitude: 22.5431, height: 5000 })

  view.on('ready', function () { console.log('地图已就绪') })
  view.on('error', function (e) {
    console.error('[MapView error]', e.code, e.message, e.data)
  })

  await view.load()
})
```

## 4. 插件

通过 `plugins` 按需装配插件，不需要的插件不要传，对应能力不会加载。

| 插件 | 说明 |
|------|------|
| `doodle` | 涂鸦标注：点、线、面、圆等地图元素的绘制与编辑 |
| `flightArea` | 自定义飞行区：限飞区、作业区、禁降区的绘制与图层显示 |
| `model` | 模型图层 |
| `topo` | 设备拓扑连线，参数与 [航线组件](./02.wayline.md) 的 `map.topo` 一致 |

每个插件可传 `true` 使用默认配置，或传入配置对象。

## 5. 自定义飞行区

自定义飞行区用于约束飞行器的作业范围。在地图上绘制并保存后，数据保存在后端，飞行区会以图层形式叠加显示在地图上。

### 5.1 飞行区类型

| 类型 | 说明 | 绘制方式 |
|------|------|----------|
| 限飞区 | 飞行器不能在该区域内飞行 | 多边形、圆形 |
| 作业区 | 飞行器只能在该区域内飞行 | 多边形、圆形 |
| 禁降区 | 飞行器不能在该区域内自动降落 | 在地图上绘制线段并设置宽度，自动生成矩形区域 |

各类型的数量上限、几何约束，以及飞行器遇到飞行区时的行为，见 [安全服务](../09.sdk/features/map/safety-service.md) 的 3.4 节「自定义飞行区说明」。

绘制时的校验与提示：

| 校验项 | 规则 |
|--------|------|
| 圆形半径 | 最小为 10 m |
| 作业区 | 作业区之间不允许重叠，重叠时提示重新绘制 |
| 作业区与限飞区 | 允许重叠，重叠部分仅限飞区生效 |
| 禁降区线段 | 单段长度 10～3000 m，线段数量不超过 50 |
| 禁降区宽度 | 10～100 m |
| 禁降区端点 | 两端存在闭合交叠区域时提示调整端点位置 |

### 5.2 插件配置

`plugins.flightArea` 传 `true` 使用默认配置即可启用。

### 5.3 数据接口

飞行区插件使用上云 API 2 提供的 HTTP 接口读写数据：

| 操作 | 方法 | 路径 |
|------|------|------|
| 查询列表 | GET | `/safety/api/v2/flight-areas` |
| 创建 | POST | `/safety/api/v2/flight-areas` |
| 更新 | PUT | `/safety/api/v2/flight-areas/{id}` |
| 删除 | DELETE | `/safety/api/v2/flight-areas/{id}` |

飞行区保存后，还需要通过 SDK 将其下发到设备，设备才会使用新的飞行区。调用方式见 [安全服务](../09.sdk/features/map/safety-service.md)。

### 5.4 生效规则与限制

- 飞行区变更不影响正在执行的航线任务，下次任务起生效。飞行中的飞行器在返航后接收变更。
- 暂不提供飞行区变更的实时消息通知：页面刷新前，航线编辑器等其他组件看到的飞行区不会随之更新，需用户手动刷新页面。
- 暂不支持飞行区的导入、导出以及颜色自定义，飞行区颜色固定。

## 6. 与其他组件的关联

飞行区作为图层在其他前端组件中同样生效：

| 组件 | 关联能力 |
|------|----------|
| 航线编辑器（`WaylineEditor`） | 叠加显示飞行区图层，并对航线做校验：航线穿越限飞区时无法提交并高亮冲突段；航线端点或航路点超出作业区时给出告警（不阻塞）；航点落在禁降区内时给出提示。面状航线可开启**限飞区绕行**，开启后航线绕开测区中的限飞区，位于限飞区边缘的航线将降低飞行速度 |
| 航线预览（`WaylineView`） | 只读显示飞行区图层 |
| 驾驶舱（`FH2.loadCockpit`） | 飞行器距飞行区边界小于 5 m 时给出告警，告警属于 HMS 告警信息 |
| 设备小窗（`FH2.loadDeviceWindow`） | 在直播画面上方给出同样的告警提示，告警属于 HMS 告警信息 |
| 设备管理（`UranusDeviceManagerApp`） | 无新增配置。如需从设备管理页跳转到自己的飞行区管理页面，可通过 [自定义按钮](./05.device-manager.md) 配置跳转地址 |

## 7. 事件与错误码

```typescript
view.on(eventName: string, callback: (data: any) => void): void
```

| 事件名 | 参数 | 说明 |
|--------|------|------|
| `ready` | 无 | 地图初始化完成 |
| `error` | `{ code: number, message: string, data?: any }` | SDK 运行时错误 |

| 错误码 | 说明 |
|--------|------|
| `6003` | 地图初始化失败 |

## 8. 常用方法

| 方法 | 说明 |
|------|------|
| `view.load()` | 加载地图，返回 Promise，需在注册事件监听后调用 |
| `view.recenter({ longitude, latitude, height? })` | 将镜头移动到指定位置；`load` 之前调用则在地图就绪后自动移动，`height` 为空则使用默认高度 |
| `view.destroy()` | 销毁地图并释放全部资源，销毁后需重新 `new MapView()` |

```javascript
view.destroy()
view = null
```
